[76. 最小覆盖子串 - 力扣（LeetCode）](https://leetcode.cn/problems/minimum-window-substring/description/?envType=study-plan-v2&envId=top-100-liked)

给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 s 中的 **最短窗口 子串**，使得该子串包含 `t` 中的每一个字符（**包括重复字符**）。如果没有这样的子串，返回空字符串 `""`。

测试用例保证答案唯一。

**示例 1：**

**输入：**s = "ADOBECODEBANC", t = "ABC"
**输出：**"BANC"
**解释：**最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

**示例 2：**

**输入：**s = "a", t = "a"
**输出：**"a"
**解释：**整个字符串 s 是最小覆盖子串。

**示例 3:**

**输入:** s = "a", t = "aa"
**输出:** ""
**解释:** t 中两个字符 'a' 均应包含在 s 的子串中，
因此没有符合条件的子字符串，返回空字符串。

**提示：**

- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 105`
- `s` 和 `t` 由英文字母组成

**进阶：**你能设计一个在 `O(m + n)` 时间内解决此问题的算法吗？

枚举 s 的子串的右端点 right ，如果子串包含 t，就不断右移左端点 left，直到子串不包含 t 为止。在移动的过程中更新最短字串的左右端点

具体思路：

1.初始化 ansLeft = -1，ansRight = m，其中 m 是 s 的长度。这两个变量用来记录**最短字串**的左右端点

2.用哈希表 cnt_t 统计 t 中各个字母出现的次数

3.初始化 left = 0，为当前枚举的子串的左端点，初始化一个空哈希表 cnt_s ，统计 s 的子串中各个字母出现的次数

4.遍历s，枚举子串右端点 right，`s[right] ++`

5.遍历 cnt_s 中的每个字母及其出现次数，如果出现次数都大于等于 cnt_t 中的字母出现次数：
- 如果 right - left < ansRight - ansLeft，说明我们找到了更短的子串，更新 ansLeft = left，ansRight = right
- 既然已经包含 t，就要移动左端点 left 缩小滑动窗口，这样才能让覆盖子串尽可能短，因此将 `s[left]--`
- left ++
- 重复这三步，直到 cnt_s 有字母的出现次数小于 cnt_t 中该字母的出现次数为止，即此时该子串不包含 t

6.什么情况下会没有最小覆盖子串？就是从来都没有出现 right - left < ansRight - ansLeft 的情况，那么 ansLeft 永远都不会被更新，也就永远都小于 0，因此如果 ansLeft 小于 0，说明没有找到符合要求的子串，返回空字符串即可

7.如果找到了符合条件的子串，返回 ansLeft 到 ansRight 之间的子串即可，

```python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        cnt_s = Counter() # s 的子串字母出现次数
        cnt_t = Counter(t) # t 中字母出现次数

        ans_left, ans_right = -1, len(s) # 最短子串的左右端点，后续在遍历的过程中进行更新
        left = 0 # 当前子串的左端点，后续枚举当前子串右端点时，如果遇到了符合条件的子串就通过移动 left 缩小滑动窗口

        for right,c in enumerate(s):
            # 枚举子串右端点
            cnt_s[c] += 1 # 遍历到的字符，出现次数加一
            while cnt_s >= cnt_t:
                # 如果子串涵盖了 t
                if right - left < ans_right - ans_left:
                    # 如果找到了更短的覆盖子串，就更新
                    ans_left, ans_right = left, right
                # 开始缩小滑动窗口，尝试找更短的覆盖子串
                # 先将左端点字母移出子串
                cnt_s[s[left]] -= 1
                # 移动左端点
                left += 1
        
        return "" if ans_left < 0 else s[ans_left: ans_right + 1]
```

时间复杂度：O(CS + T)，其中 S 是 s 的长度，T 是 t 的长度，C 是字符集合 Counter 的长度

因为 cnt_s >= cnt_t 这里的比较是需要花 O(C) 的时间的，也就是说 left 每增加一，就要花费 O(C) 时间，而 left 最多增加 S 次，再加上统计 t 字母出现次数的时间 O(T)，就能得到时间复杂度 O(CS + T)

### 优化

判断是否涵盖的方法是：cnt_s >= cnt_t，这种方法每次都要花费 O(C) 的时间判断，可以将其优化为 O(1)

用一个变量 g 表示当前子串中有 g 种字母的出现次数大于等于 t 中对应字母的出现次数，这样一来，假设 t 有 k 个不同的字母，那么判断涵盖的条件就变为 g = k 了

定义 `diff[x] = cnt_s[x] - cnt_t[x]`，如果 `diff[x] = 0`，表示窗口内字母 x 的出现次数和 t 的一样多

如果 x 进入窗口后，`diff[x] = 0`，说明因为窗口因为 x 的加入，使得窗口内 x 的出现次数与 t 中 x 的出现次数持平了，那么 g 增加 1. 这里需要注意，条件不能是 `diff[x] ≥ 0`，因为如果 `diff[x] ≥ 0`，那么即便窗口中再出现 x ，子串中字母出现次数相比 t 中对应字母的出现次数更高（或者持平）的字母种数 不会发生变化，因为我们看的是种类的差值，而不是一个字母出现次数的差值

如果 x 离开窗口前，`diff[x] = 0`，说明窗口会因为 x 的离开，使得窗口内 x 的出现次数小于 t 中 x 的出现次数，那么 g 减少 1

这是比较经典的滑动窗口中维护某个元素出现次数的办法

```python
from collections import defaultdict
import ast

def minWindow(s: str, t: str) -> str:
    diff = defaultdict(int) # 窗口中每种字母个数 与 t 中每种字母个数 的差值
    for c in t:
        diff[c] -= 1 # 对 diff 进行初始化：初始时没有窗口
    k = len(diff) # t 中有 k 种不同的字母

    ans_left, ans_right = -1, len(s)
    g = 0 # 窗口内有 g 种字母的出现次数 ≥ t 中对应字母的出现次数
    # 一开始 g 为 0，因为没有窗口
    left = 0
    
    for right, c in enumerate(s):
        diff[c] += 1
        if diff[c] == 0:
            # 如果因为 c 的到来使得窗口内 c 的出现次数与 t 持平，增加 g
            g += 1 # 出现次数持平的字母种类多了一个
            
        while g == k:
            # 如果涵盖
            if right - left < ans_right - ans_left:
                ans_left, ans_right = left, right
            l = s[left] # 左端点字母

            if diff[l] == 0:
                # 如果窗口内 l 的出现次数 和 t 一样
                # 那么 l 移出后，窗口内 l 的出现次数就会小于 t
                # 那么窗口内出现次数更多或持平的字母种类将会少一种
                # 因此 g 要减一
                g -= 1
            diff[l] -= 1 # 左端点字母移出子串
            left += 1 # 左端点右移
    return "" if ans_left < 0 else s[ans_left: ans_right + 1]

def read_cases(filename):
    cases = []
    with open(filename) as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
                
            s_line, t_line = line.split(",")

            s = ast.literal_eval(
                s_line.split("=", 1)[1].strip()
            )
            t = ast.literal_eval(
                t_line.split("=", 1)[1].strip()
            )
            cases.append((s,t))
    return cases

def main():
    cases = read_cases("cases.txt")
    for s, t in cases:
        print(f"s = {s}")
        print(f"t = {t}"
        print(minWindow(s, t))
        print()

if __name__ == "__main__":
    main()
```

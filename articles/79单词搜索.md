[79. 单词搜索 - 力扣（LeetCode）](https://leetcode.cn/problems/word-search/?envType=study-plan-v2&envId=top-100-liked)

给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/11/04/word2.jpg)

**输入：**board = `[['A','B','C','E'],['S','F','C','S'],['A','D','E','E']]`, word = "ABCCED"
**输出：**true

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/11/04/word-1.jpg)

**输入：**board = `[['A','B','C','E'],['S','F','C','S'],['A','D','E','E']]`, word = "SEE"
**输出：**true

**示例 3：**

![](https://assets.leetcode.com/uploads/2020/10/15/word3.jpg)

**输入：**board = `[['A','B','C','E'],['S','F','C','S'],['A','D','E','E']]`, word = "ABCB"
**输出：**false

**提示：**

- `m == board.length`
- `n = board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 仅由大小写英文字母组成

**进阶：**你可以使用搜索剪枝的技术来优化解决方案，使其在 `board` 更大的情况下可以更快解决问题？

比较容易想到 dfs，思路如下：

设 dfs(i, j, k) 表示当前在 `board[i][j]` 这个格子，尝试匹配 `word[k]`

如果 `board[i][j] != word[k]`，直接返回 false

如果 `board[i][j] == word[k]` 且 `k == len(word) - 1`，即已经遍历到了 word 的最后一个元素，直接返回 true

如果 `board[i][j] == word[k]` 且 `k != len(word) - 1`，开始 dfs：枚举 (i, j) 周围的四个格子 (x, y)，如果 (x, y) 没有出界，递归调用 dfs(x, y, k + 1)，如果其返回 true ，则 dfs(i, j, k) 也返回 true，如果四个 (x, y) 都返回 false，则 dfs(i, j, k) 返回 false

同时，每遍历到 `board[i][j]`，就将其置零，如果 dfs(i, j, k) 返回 false 再将其恢复原来的值，这样就可以避免重复进行 dfs

注意到示例三，在 word 中 B 出现了两次，但在 board 中只出现了一次，必然返回 false，因此我们可以先判断 word 中的某个字母的出现次数是否大于其在 board 中的出现次数，如果是，直接返回 false，不需要 dfs

另外由示例一二可以看出，对于我们肉眼搜索而言，我们会先找 word 的第一个字母，然后再进行 dfs，例如示例一中我们会先看到两个 A，示例二中我们会先看到两个 S，选哪个进行 dfs ？

事实上，直觉告诉我们，我们希望从那个在 board 中出现次数最少的字母入手进行 dfs，比如 word = xyz，而 board 中 x 的数量极其庞大，但只有一个 z，我们自然会先定位到 z 进行 dfs

设 word 的第一个字母在 board 中出现了 x 次，最后一个字母在 board 中出现了 y 次

如果 y < x ，那么就将 word 反转，即从最后一个字母开始 dfs，这样可以减少 dfs 的次数

```python
class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        cnt = Counter(c for row in board for c in row)
        # 但凡 word 中有一个字母出现的次数比在 board 中出现的次数要多，都直接返回 False
        if not Counter(word) <= cnt:
            return False
        
        if cnt[word[-1]] < cnt[word[0]]:
            word = word[::-1]
        
        m, n = len(board), len(board[0])
        def dfs(i: int, j: int, k: int) -> bool:
            if board[i][j] != word[k]:
                return False
            if k == len(word) - 1:
                return True
            board[i][j] = '' # 标记
            for x, y in (i, j - 1), (i, j + 1), (i - 1, j), (i + 1, j):
                if 0 <= x < m and 0 <= y < n and dfs(x, y, k + 1):
                    return True
            board[i][j] = word[k] # 没找到，恢复
            return False
        return any(dfs(i, j, 0) for i in range(m) for j in range(n))
```

```python
import ast
from typing import List
from collections import Counter

def exist(board: List[List[str]], word: str) -> bool:
    cnt = Counter(c for row in board for c in row)
    if not Counter(word) <= cnt:
        return False
        
    if cnt[word[-1]] > cnt[word[0]]:
        word = word[::-1]

    m, n = len(board), len(board[0])
    def dfs(i: int, j: int, k: int) -> bool:
        if board[i][j] != word[k]:
            return False

        if k == len(word) - 1:
            return True

        board[i][j] = ''
        for x, y in (i, j - 1), (i, j + 1), (i + 1, j), (i - 1, j):
            if 0 <= x < m and 0 <= y < n and dfs(x, y, k + 1):
                return True

        board[i][j] = word[k]
        return False
    return any(dfs(i, j, 0) for i in range(m) for j in range(n))
  

def read_cases(filename):
    cases = []
    with open(filename, "r") as f:
        lines = [
            line.strip() for line in f if line.strip()
        ] # 去掉测试用例直接隔着的空行

    for i in range(0, len(lines), 2):
        # 每两行都是新的测试用例
        board_line = lines[i]
        word_line = lines[i + 1]

        board = ast.literal_eval(
            board_line.split("=", 1)[1].strip()
        )

        word = ast.literal_eval(
            word_line.split("=", 1)[1].strip()
        )

        cases.append(
            (board, word)
        )
    return cases


def main():
    cases = read_cases("case.txt")
    for board, word in cases:
        print(f"board = {board}")
        print(f"word = {word}")

        result = exist(board, word)
        print (f"result = {result}")
        print()

if __name__ == "__main__":
    main()
```

[76. Minimum Window Substring - LeetCode](https://leetcode.cn/problems/minimum-window-substring/description/?envType=study-plan-v2&envId=top-100-liked)

Given two strings `s` and `t` of lengths `m` and `n` respectively, return the **shortest window substring** of `s` that contains every character in `t` (including duplicate characters). If no such substring exists, return the empty string `""`.

The test cases guarantee that the answer is unique.

**Example 1:**

**Input:** s = "ADOBECODEBANC", t = "ABC"
**Output:** "BANC"
**Explanation:** The minimum window substring "BANC" contains 'A', 'B', and 'C' from string `t`.

**Example 2:**

**Input:** s = "a", t = "a"
**Output:** "a"
**Explanation:** The entire string `s` is the minimum window substring.

**Example 3:**

**Input:** s = "a", t = "aa"
**Output:** ""
**Explanation:** Both 'a' characters in `t` must be contained in the substring of `s`, so no qualifying substring exists.

**Constraints:**

- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 105`
- `s` and `t` consist of English letters.

**Follow-up:** Can you design an algorithm that solves this problem in `O(m + n)` time?

Enumerate the right endpoint `right` of a substring of `s`. If the substring contains `t`, continuously move the left endpoint `left` to the right until the substring no longer contains `t`. Update the left and right endpoints of the shortest string while moving.

Specific steps:

1. Initialize `ansLeft = -1` and `ansRight = m`, where `m` is the length of `s`. These record the endpoints of the **shortest substring**.
2. Use a hash table `cnt_t` to count the occurrences of each letter in `t`.
3. Initialize `left = 0` as the left endpoint of the current substring, and initialize an empty hash table `cnt_s` to count letters in the substring of `s`.
4. Traverse `s`, enumerating the right endpoint `right`, and increment `s[right]`.
5. Traverse each letter in `cnt_s` and its occurrence count. If every count is at least the corresponding count in `cnt_t`:
   - If `right - left < ansRight - ansLeft`, a shorter substring has been found; update `ansLeft = left` and `ansRight = right`.
   - Since `t` is already covered, move `left` to shrink the sliding window and make the covering substring as short as possible, then decrement `s[left]`.
   - Increment `left`.
   - Repeat these three steps until an occurrence count in `cnt_s` is less than the corresponding count in `cnt_t`, meaning the substring no longer covers `t`.
6. There is no minimum window substring if `right - left < ansRight - ansLeft` never occurs. Then `ansLeft` is never updated and remains less than 0, so return the empty string.
7. If a qualifying substring is found, return the substring from `ansLeft` to `ansRight`.

```python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        cnt_s = Counter() # occurrence counts of letters in the substring of s
        cnt_t = Counter(t) # occurrence counts of letters in t

        ans_left, ans_right = -1, len(s) # endpoints of the shortest substring, updated during traversal
        left = 0 # left endpoint of the current substring; move it to shrink the window when the substring covers t

        for right,c in enumerate(s):
            # enumerate the right endpoint of the substring
            cnt_s[c] += 1 # increment the occurrence count of the traversed character
            while cnt_s >= cnt_t:
                # if the substring covers t
                if right - left < ans_right - ans_left:
                    # update when a shorter covering substring is found
                    ans_left, ans_right = left, right
                # shrink the sliding window to find a shorter covering substring
                # first remove the left-end character from the substring
                cnt_s[s[left]] -= 1
                # move the left endpoint
                left += 1

        return "" if ans_left < 0 else s[ans_left: ans_right + 1]
```

Time complexity: `O(CS + T)`, where `S` is the length of `s`, `T` is the length of `t`, and `C` is the length of the character set in `Counter`.

The comparison `cnt_s >= cnt_t` takes `O(C)` time. Therefore, every increment of `left` costs `O(C)` time, and `left` increases at most `S` times. Adding the `O(T)` time to count the letters in `t` gives `O(CS + T)`.

### Optimization

The covering check `cnt_s >= cnt_t` costs `O(C)` each time. We can optimize it to `O(1)`.

Let `g` represent the number of letter types in the current substring whose occurrence counts are at least the corresponding counts in `t`. If `t` has `k` distinct letters, the covering condition becomes `g = k`.

Define `diff[x] = cnt_s[x] - cnt_t[x]`. If `diff[x] = 0`, the occurrence counts of letter `x` in the window and in `t` are equal.

When `x` enters the window and `diff[x] = 0`, the addition of `x` makes the count of `x` in the window equal to its count in `t`, so `g` increases by 1. The condition cannot be `diff[x] ≥ 0`: even if `diff[x] ≥ 0`, another `x` entering the substring does not change the number of letter types whose counts are greater than or equal to those in `t`. We track the difference by type, not the difference in the count of one occurrence.

If `diff[x] = 0` before `x` leaves the window, removing `x` makes its count smaller than in `t`, so `g` decreases by 1.

This is a classic way to maintain element counts in a sliding window.

```python
from collections import defaultdict
import ast

def minWindow(s: str, t: str) -> str:
    diff = defaultdict(int) # difference between each letter count in the window and in t
    for c in t:
        diff[c] -= 1 # initialize diff: initially there is no window
    k = len(diff) # number of distinct letters in t

    ans_left, ans_right = -1, len(s)
    g = 0 # number of letter types in the window whose counts are >= their counts in t
    # initially g is 0 because there is no window
    left = 0

    for right, c in enumerate(s):
        diff[c] += 1
        if diff[c] == 0:
            # c makes its count in the window equal to its count in t, so increase g
            g += 1 # there is one more letter type with equal counts

        while g == k:
            # if the window covers t
            if right - left < ans_right - ans_left:
                ans_left, ans_right = left, right
            l = s[left] # left-end character

            if diff[l] == 0:
                # the count of l in the window equals its count in t
                # after l leaves, the count of l in the window becomes smaller than in t
                # so the number of letter types with greater or equal counts decreases by one
                g -= 1
            diff[l] -= 1 # remove the left-end character from the substring
            left += 1 # move the left endpoint right
    return "" if ans_left < 0 else s[ans_left: ans_right + 1]

def read_cases(filename):
    cases = []
    with open(filename) as f:
        for line in f:
            line = line.strip()
            if not line:
                continue

            s_line, t_line = line.split(",")

            s = ast.literal_eval(
                s_line.split("=", 1)[1].strip()
            )
            t = ast.literal_eval(
                t_line.split("=", 1)[1].strip()
            )
            cases.append((s,t))
    return cases

def main():
    cases = read_cases("cases.txt")
    for s, t in cases:
        print(f"s = {s}")
        print(f"t = {t}")
        print(minWindow(s, t))
        print()

if __name__ == "__main__":
    main()
```

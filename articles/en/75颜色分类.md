Link: [75. Sort Colors - LeetCode](https://leetcode.cn/problems/sort-colors/description/?envType=study-plan-v2&envId=top-100-liked)

Given an array `nums` containing `n` objects colored red, white, or blue, sort them **[in place](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)** so that objects of the same color are adjacent, with the colors ordered red, white, and blue.

We use the integers `0`, `1`, and `2` to represent red, white, and blue respectively.

You must solve this problem without using the library's built-in `sort` function.

**Example 1:**

**Input:** nums = `[2,0,2,1,1,0]`
**Output:** `[0,0,1,1,2,2]`

**Example 2:**

**Input:** nums = `[2,0,1]`
**Output:** `[0,1,2]`

**Constraints:**

- `n == nums.length`
- `1 <= n <= 300`
- `nums[i]` is either `0`, `1`, or `2`.

**Follow-up:**

- Can you solve this with a one-pass algorithm using only constant space?

### Method 1: One Pointer, Two Passes

In the first pass, move all 0s forward; in the second pass, place all 1s after the 0s.

Use one pointer to maintain the tail of the sorted part, which identifies the next position to sort.

Java

```java
class Solution {
    public void sortColors(int[] nums) {
        // put 0s first in the first pass, then put 1s after the 0s in the second pass
        // use one pointer to mark the end of the sorted part (the next position after its last element); initially it is at element 0
        int n = nums.length;
        int ptr = 0;
        // first pass
        for(int i=0;i<n;i++) {
            if(nums[i] == 0) {
                int temp = nums[i];
                nums[i] = nums[ptr];
                nums[ptr] = temp;
                ptr++;
            }
        }

        // second pass
        for(int i=ptr;i<n;i++) {
            if(nums[i] == 1) {
                int temp = nums[i];
                nums[i] = nums[ptr];
                nums[ptr] = temp;
                ptr++;
            }
        }
    }
}
```

### Method 2: Counting, One Pass

Process the array while recording the counts of 0s and 1s.

First record the value of the element, then assign 2 to that position. Since non-2 values need to be counted, assign 2 uniformly first.

Introduce two pointers: `p0` records the last position assigned 0, and `p1` records the last position assigned 1.

If the current element is 0 or 1, first assign 1 to it and move `p1` forward. Whether the current element is 0 or 1, all 0s must be placed before all 1s, so the last position assigned 1 must move forward.

Then check whether the current element is 0. If it is, move `p0` forward as well. Since `p1` has already moved forward, no additional movement is needed.

You can regard this as opening a new array to fill with 0, 1, and 2. Therefore, we only need to know the number of 0s and 1s in the original array. `p0` is actually the number of 0s in the traversed array, and `p1-p0` is the number of 1s.

```java
class Solution {
    public void sortColors(int[] nums) {
        int p0 = 0;
        int p1 = 0;
        int n = nums.length;
        for(int i=0;i<n;i++) {
            int temp = nums[i];
            nums[i] = 2;
            if(temp <= 1) {
                nums[p1++] = 1;
            }
            if(temp == 0) {
                nums[p0++] = 0;
            }
        }
    }
}
```

Problem link: [300. Longest Increasing Subsequence - LeetCode](https://leetcode.cn/problems/longest-increasing-subsequence/)

Given an integer array `nums`, find the length of its longest strictly increasing subsequence.

A **subsequence** is a sequence derived from an array by deleting or not deleting elements without changing the order of the remaining elements. For example, `[3,6,2,7]` is a subsequence of `[0,3,1,6,2,2,7]`.

**Example 1:**

```
Input: nums = [10,9,2,5,3,7,101,18]
Output: 4
Explanation: The longest increasing subsequence is [2,3,7,101], so its length is 4.
```

**Example 2:**

```
Input: nums = [0,1,0,3,2,3]
Output: 4
```

**Example 3:**

```
Input: nums = [7,7,7,7,7,7,7]
Output: 1
```

**Constraints:**

- `1 <= nums.length <= 2500`
- `-104 <= nums[i] <= 104`

**Follow-up:**

- Can you reduce the time complexity of the algorithm to `O(n log(n))`?

### Method 1: Dynamic Programming

Consider the general case. To calculate `dp[i]`, where `dp[i]` represents the length of the longest increasing subsequence ending at `nums[i]`, we only need to find `nums[j]` before `nums[i]` such that it is smaller. Then `dp[i]` equals `dp[j] + 1`.

Since we need the maximum, update the maximum with `max` while traversing.

The recurrence has been obtained. Next consider initialization. Clearly, initialize every element to 1, because a single number can also form a subsequence.

Finally, use `max` to update the largest `dp[i]`.

Java
```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        Arrays.fill(dp, 1);
        int ans = dp[0];
        for(int i = 1; i < n; i++) {
            for(int j = i - 1; j >= 0; j--) {
                if(nums[i] > nums[j]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            ans = Math.max(ans, dp[i]);
        }
        return ans;
    }
}
```

### Method 2: Greedy + Binary Search

Suppose `nums` is `[1,2,99999,3,4]`. After traversing the first two elements, 1 and 2, the current longest increasing subsequence (hereafter LIS) is `[1,2]`.

Will you choose 99999 or the later 3 to add to the LIS?

Clearly, you should choose the smaller 3. If you choose 99999, you will miss the 4 after 3.

Choosing 3 gives the correct LIS, `[1,2,3,4]`.

This is a greedy idea: to make the increasing sequence longer, we should make it grow as slowly as possible, avoiding the possibility of missing a later increasing sequence. This represents the “most likely” possibility.

Applied to a specific array, our selection strategy is still to choose an element larger than the elements in the LIS, but with an additional condition: among those larger elements, choose the smallest one. But how do we know during traversal whether a later element is smaller?

We can record the current LIS length `len`, and use an array `d` to record the minimum possible last element of an LIS (that is, its maximum value). `d[len]` represents the minimum last element among all LISs of length `len`.

Clearly, `d[i]` increases as `i` increases. If `d[j] ≥ d[i]` and `j < i`, consider removing `i - j` elements from the end of an increasing subsequence of length `i`. The sequence then has length `j`, and its jth element `x` (the last element) must be smaller than `d[i]`, because it is not the last element and therefore must be smaller than the last element. It is also smaller than `d[j]`. Thus, we find an increasing subsequence of length `j` whose last element is smaller than `d[j]`, but by definition `d[j]` is the minimum last element of an LIS of length `j`, which is a contradiction. Therefore, monotonicity is proved.

If the traversed element `nums[i]` is smaller than `d[len]`, there is a possibility with a slower growth rate. Which subsequence can grow more slowly? To answer this, find the first element from right to left in `d` that is smaller than `nums[i]`. Since `d` is ordered, binary search can be used. Suppose its position is `k`. After replacing `d[k+1]` with `nums[i]`, the growth rate of `d[1...k+1]` is slower than before the replacement, so the possibility that an LIS of length `k+1` becomes longer later increases.

If `nums[i]` is larger than `d[len]`, then `nums[i]` can become the last element of an LIS of length `len+1`. Simply increment `len` and set `d[len+1]` to `nums[i]`. Since the length has changed, there is only one LIS of length `len+1`, so the minimum last element can only be the newly added `nums[i]`.

Java
```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        if(n == 0) return 0;
        int[] d = new int[n + 1]; // d[len] is the minimum last element of an LIS of length len
        int len = 1; // length of the LIS; initially it contains only the first element, so it is 1
        d[len] = nums[0]; // initially len is 1 and the LIS consists of the first element, so its minimum is that element itself

        for(int i = 1; i < n; i++) {
            if(nums[i] > d[len]) {
                // the maximum of the LIS of length len with the minimum last element encounters a larger element, so add it to the LIS
                d[++len] = nums[i]; // the original length was len and is now len+1; d[len+1] is the minimum last element of an LIS of length len+1
            } else {
                // use binary search to find the first position pos from right to left in d whose value is smaller than nums[i], then set d[pos+1] to nums[i]
                // if every element in d is larger than nums[i], update d[1]. An LIS of length 1 ending at nums[i] has the smallest last element, so pos initially equals 0
                int pos = 0;
                int l = 1, r = len; // d[0] has no actual meaning, so the left endpoint is 1 and the right endpoint is len
                while(l <= r) {
                    int mid = (l + r) >> 1;
                    if(d[mid] < nums[i]) {
                        pos = mid;
                        l = mid + 1;
                    } else {
                        r = mid - 1;
                    }
                }
                d[pos + 1] = nums[i];
            }
        }
        return len;
    }
}
```

Link: [322. Coin Change - LeetCode](https://leetcode.cn/problems/coin-change/description/?envType=study-plan-v2&envId=top-100-liked)

You are given an integer array `coins`, representing coins of different denominations, and an integer `amount`, representing a total amount of money.

Calculate and return the **minimum number of coins** needed to make up that total amount. If no combination of coins can make up the total amount, return `-1`.

You may assume that the number of coins of each denomination is unlimited.

**Example 1:**

```
Input: coins = [1, 2, 5], amount = 11
Output: 3
Explanation: 11 = 5 + 5 + 1
```

**Example 2:**

```
Input: coins = [2], amount = 3
Output: -1
```

**Example 3:**

```
Input: coins = [1], amount = 0
Output: 0
```

**Constraints:**

- `1 <= coins.length <= 12`
- `1 <= coins[i] <= 231 - 1`
- `0 <= amount <= 104`

This is essentially the climbing stairs problem. In the climbing stairs problem, you can take only 1 or 2 steps at a time. In this problem, the number of steps you can take at a time is the value of an element in the `coins` array.

For climbing stairs, to reach stair `i`, you must arrive either from stair `i-2` or stair `i-1`, because you can take only 1 or 2 steps at a time. Choose the solution with the minimum number of steps.

Here, the number of steps you can take at a time is an element in `coins`. To reach stair `i`, you must arrive from stair `i-coins[j]`, where `coins[j]` is the element currently being traversed in the `coins` array. Choose the solution with the minimum number of steps to reach stair `i-coins[j]`.

```java
class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1]; // we ultimately need to calculate dp[amount]
        Arrays.fill(dp, amount + 1); // initially, we do not know how many steps can be taken at once, so assume every stair is unreachable
        dp[0] = 0; // except stair 0, because we are already at stair 0

        for(int i = 1; i <= amount; i++) {
            for(int j = 0; j < coins.length; j++) {
                if(i >= coins[j]) {
                    dp[i] = Math.min(dp[i],dp[i - coins[j]] + 1);
                }
            }
        }
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
```

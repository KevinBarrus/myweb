[208. Implement Trie (Prefix Tree) - LeetCode](https://leetcode.cn/problems/implement-trie-prefix-tree/description/?envType=study-plan-v2&envId=top-100-liked)

**[Trie](https://baike.baidu.com/item/%E5%AD%97%E5%85%B8%E6%A0%91/9825209?fr=aladdin)** (pronounced like “try”), also called a **prefix tree**, is a tree data structure used to efficiently store and retrieve keys in a dataset of strings. This data structure has many applications, such as autocomplete and spell checking.

Implement the `Trie` class:

- `Trie()` initializes the prefix tree object.
- `void insert(String word)` inserts the string `word` into the prefix tree.
- `boolean search(String word)` returns `true` if the string `word` is in the prefix tree, meaning it was inserted before the search; otherwise, it returns `false`.
- `boolean startsWith(String prefix)` returns `true` if one of the prefixes of a previously inserted string `word` is `prefix`; otherwise, it returns `false`.

**Example:**

**Input**
`["Trie", "insert", "search", "search", "startsWith", "insert", "search"]`
`[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]`
**Output**
`[null, null, true, false, true, null, true]`

**Explanation**
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // returns True
trie.search("app");     // returns False
trie.startsWith("app"); // returns True
trie.insert("app");
trie.search("app");     // returns True

**Constraints:**

- `1 <= word.length, prefix.length <= 2000`
- `word` and `prefix` consist only of lowercase English letters.
- The total number of calls to `insert`, `search`, and `startsWith` does not exceed `3 * 104`.

If a word contains only the two letters a and b, it becomes a binary tree. Suppose a is the left child and b is the right child (that is, go left for a and right for b).

`insert`: Suppose we insert `aabb`. This is equivalent to adding a binary-tree path of “left, left, right, right” and marking the last node as a terminal node. If we insert `aabba` afterward, this is equivalent to adding a path of “left, left, right, right, left”, adding a left child to the terminal node of the previous path, and marking this left child as a terminal node.

`search`: For example, searching for `aabb` is equivalent to checking whether a “left, left, right, right” path exists in the binary tree and whether its last node is a terminal node.

`startsWith`: This is equivalent to `search`, except that the last node does not need to be a terminal node.

Now we have words, which are combinations of 26 letters, so the binary tree becomes a 26-ary tree. Each node in the 26-ary tree contains a list of 26 child nodes and a Boolean variable `end` marking whether the node is a terminal node.

`insert`:

1. Traverse `word`, using `cur` to represent the node in the tree corresponding to the current character. Initially, `cur` is `root`.
2. If `word[i]` is not a child of `cur`, create a node `node` as a child of `cur`. If `word[i]` is a, `son[0]` in `cur`'s child array equals the newly created node `node`, and so on for the other characters.
3. Update `cur` to the corresponding node in the child list.
4. After traversing `word`, set `cur.end` to `true`.

Because `startsWith` and `search` overlap heavily, we can use a common `find` function:

1. Traverse the string `word`, using `cur` to represent the node in the tree corresponding to the current character. Initially, `cur` is `root`.
2. If `word[i]` is not a child of `cur`, return 0. After receiving 0, `search` and `startsWith` return `false`.
3. Update `cur` to the corresponding node in the child list.
4. After traversal ends, if `cur.end` is `false`, return 1; otherwise, return 2.
5. If `search` receives 2, return `true`; otherwise, return `false`.
6. If `startsWith` receives a non-zero number, return `true`; otherwise, return `false`.

```python
class Trie:

    def __init__(self) :
        self.root = Node()

    def insert(self, word: str) -> None :
        cur = self.root # represents the position of the current character in the tree
        for c in word :
            if c not in cur.son :
                cur.son[c] = Node()
            cur = cur.son[c]
        cur.end = True # traversal complete; mark the terminal node

    def find(self, word : str) -> int :
        cur = self.root
        for c in word :
            if c not in cur.son :
                return 0
            cur = cur.son[c]
        return 2 if cur.end else 1 # if the last character is a terminal node, it is an exact match and search returns true

    def search(self, word: str) -> bool :
        return self.find(word) == 2

    def startsWith(self, prefix: str) -> bool :
        return self.find(prefix) != 0

class Node :
    __slots__ = 'son', 'end'

    def __init__(self) :
        self.son = {}
        self.end = False
```

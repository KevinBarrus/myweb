#### Problem 1: [206. Reverse Linked List - LeetCode](https://leetcode.cn/problems/reverse-linked-list/)

Given the head node `head` of a singly linked list, reverse the linked list and return the reversed list.

**Example 1:**

![img](https://assets.leetcode.com/uploads/2021/02/19/rev1ex1.jpg)

```
Input: head = [1,2,3,4,5]
Output: [5,4,3,2,1]
```

**Example 2:**

![img](https://assets.leetcode.com/uploads/2021/02/19/rev1ex2.jpg)

```
Input: head = [1,2]
Output: [2,1]
```

**Example 3:**

```
Input: head = []
Output: []
```

**Constraints:**

- The number of nodes in the linked list is in the range `[0, 5000]`.
- `-5000 <= Node.val <= 5000`

**Follow-up:** The linked list can be reversed iteratively or recursively. Can you solve this problem using both methods?

Method 1: Iteration

Starting from the head, adjust the pointers in pairs. For `A->B->C`, after changing it to `A<-B->C`, we need to record C; otherwise, we do not know which node should point to B. In addition, to prevent the first and second nodes from pointing to each other, the first position should be an empty node and the second position should be the first node.

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode*prev=nullptr;
        ListNode*curr=head;
        while(curr) {
            ListNode*tmp=curr->next;
            curr->next=prev;
            prev=cur;
            curr=tmp;
        }
        return prev;
    }
};
```

Method 2: Recursion

For the linked list `A->B->C->D`, to reverse `A->B`, first reverse `B->C`; to reverse `B->C`, first reverse `C->D`. This is the “descending” step. Once we find that D has nothing after it, we officially begin reversing and then return from the stack one by one. This is the “ascending” step.

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* func(ListNode*prev,ListNode*curr) {
        // determine the termination condition, then ascend
        if(curr==nullptr) return prev;

        // process one level of logic
        ListNode*tmp=curr->next;
        curr->next=prev;

        // descend
        return func(curr,tmp);
    }
    ListNode* reverseList(ListNode* head) {
        return func(nullptr,head);// still avoid the first two nodes pointing to each other
    }
};
```

The reason to directly return `func(nullptr,head)` is that the function for every pair `(prev,curr)` returns the return value of the function for the next pair `(curr,tmp)`. In other words, `func(A,B)` depends on `func(B,C)`, and `func(B,C)` depends on `func(C,D)`. The final return value is `func(D,nullptr)`, which is the head of the new linked list.

#### Problem 2: [92. Reverse Linked List II - LeetCode](https://leetcode.cn/problems/reverse-linked-list-ii/)

Given the head pointer `head` of a singly linked list and two integers `left` and `right`, where `left <= right`, reverse the nodes from position `left` to position `right` and return the **reversed linked list**.

**Example 1:**

![img](https://assets.leetcode.com/uploads/2021/02/19/rev2ex2.jpg)

```
Input: head = [1,2,3,4,5], left = 2, right = 4
Output: [1,4,3,2,5]
```

**Example 2:**

```
Input: head = [5], left = 1, right = 1
Output: [5]
```

**Constraints:**

- The number of nodes in the linked list is `n`.
- `1 <= n <= 500`
- `-500 <= Node.val <= 500`
- `1 <= left <= right <= n`

**Follow-up:** Can you complete the reversal in one scan?

The difference is that this problem only requires reversing part of the linked list. The ideas are largely the same; Problem 1 can also be understood as reversing part of a linked list, except that both ends are `nullptr`.

First, create a dummy head node `dummy_head`, because the first node may move elsewhere as a result of the reversal.

Method 1:

Find the node before the leftmost node and the node after the rightmost node of the part to reverse, extract that part separately, return to the previous problem, and adjust the pointers.

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    void reverse(ListNode*head) {
        ListNode*pre=nullptr;
        ListNode*cur=head;
        while(cur) {
            ListNode*tmp=cur->next;
            cur->next=pre;
            pre=cur;
            cur=tmp;
        }
    }
    ListNode* reverseBetween(ListNode* head, int left, int right) {
        ListNode*dummy_head=new ListNode(0);
        dummy_head->next=head;
        ListNode*prev=dummy_head;
        for(int i=0;i<left-1;i++) {
            prev=prev->next;//find the node before the leftmost node of the part to reverse
        }
        ListNode*left_node=prev->next;//leftmost node of the part to reverse
        ListNode*right_node=prev;
        for(int i=0;i<right-left+1;i++) {
            right_node=right_node->next;
        }
        // right_node is now the rightmost node of the part to reverse
        ListNode*curr=right_node->next;//find the node after the rightmost node of the part to reverse

        // extract the part to reverse; this returns to Reverse Linked List I
        prev->next=nullptr;
        right_node->next=nullptr;
        reverse(left_node);

        // connect the parts
        prev->next=right_node;
        left_node->next=curr;
        return dummy_head->next;
    }
};
```

Method 2:

Do not extract the part to reverse separately; operate directly after finding the leftmost node.

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    void reverse(ListNode*head) {
        ListNode*pre=nullptr;
        ListNode*cur=head;
        while(cur) {
            ListNode*tmp=cur->next;
            cur->next=pre;
            pre=cur;
            cur=tmp;
        }
    }
    ListNode* reverseBetween(ListNode* head, int left, int right) {
        ListNode*dummy_head=new ListNode(0);
        dummy_head->next=head;
        ListNode*prev=dummy_head;
        for(int i=0;i<left-1;i++) {
            prev=prev->next;//find the node before the leftmost node of the part to reverse
        }
        ListNode*curr=prev->next;//leftmost node of the part to reverse
        ListNode*nxt;
        for(int i=0;i<right-left;i++) {
            nxt=curr->next;
            //swap positions
            curr->next=nxt->next;

            //move nxt to the front
            nxt->next=prev->next;
            prev->next=nxt;
        }
        return dummy_head->next;
    }
};
```

Each operation not only swaps positions, but also moves the later node to the front, thereby reversing the part.

#### Problem 3: [2130. Maximum Twin Sum of a Linked List - LeetCode](https://leetcode.cn/problems/maximum-twin-sum-of-a-linked-list/description/)

In a linked list of size `n`, where `n` is **even**, for `0 <= i <= (n / 2) - 1`, the twin node of the ith node (0-indexed) is the `(n-1-i)`th node.

- For example, when `n = 4`, node 0 is the twin of node 3, and node 1 is the twin of node 2. These are all twin pairs in a linked list of length `n = 4`.

The **twin sum** is the sum of the values of a node and its twin node.

Given the head node `head` of an even-length linked list, return the **maximum twin sum** of the linked list.

**Example 1:**

![img](https://assets.leetcode.com/uploads/2021/12/03/eg1drawio.png)

```
Input: head = [5,4,2,1]
Output: 6
Explanation:
Nodes 0 and 1 are the twins of nodes 3 and 2 respectively. Both twin sums are 6.
There are no other twin nodes.
Therefore, the maximum twin sum is 6.
```

**Example 2:**

![img](https://assets.leetcode.com/uploads/2021/12/03/eg2drawio.png)

```
Input: head = [4,2,2,3]
Output: 7
Explanation:
The twin pairs in the linked list are:
- Node 0 is the twin of node 3, and the twin sum is 4 + 3 = 7.
- Node 1 is the twin of node 2, and the twin sum is 2 + 2 = 4.
Therefore, the maximum twin sum is max(7, 4) = 7.
```

**Example 3:**

![img](https://assets.leetcode.com/uploads/2021/12/03/eg3drawio.png)

```
Input: head = [1,100000]
Output: 100001
Explanation:
There is only one pair of twin nodes, whose twin sum is 1 + 100000 = 100001.
```

**Constraints:**

- The number of nodes in the linked list is an **even** number in `[2, 105]`.
- `1 <= Node.val <= 105`

Method 1: Convert to an Array

This is the simplest method: push the node values into an array one by one, then traverse it.

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    int pairSum(ListNode* head) {
        vector<int>vec;
        while(head){
            vec.push_back(head->val);
            head=head->next;
        }
        int ans=0;
        for(int i=0;i<vec.size()/2;i++) {
            ans=max(ans,vec[i]+vec[vec.size()-1-i]);
        }
        return ans;
    }
};
```

Method 2: Fast and Slow Pointers + Reverse Linked List

In an interview, we generally will not be asked to directly put linked-list node values into an array, so we need to consider another approach.

We want to use an array because it can be traversed in reverse order, while a linked list cannot. However, this idea gives us an important insight: we can use fast and slow pointers to find the middle, while reversing the first half of the linked list. If we reverse the second half, we would need to start from the head again when calculating twin sums. Therefore, reverse the first half while the slow pointer advances. Once it reaches the middle, `prev` and `curr` can move toward each other.

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    int pairSum(ListNode* head) {
        ListNode*slow_prev=nullptr;
        ListNode*slow_curr=head;
        ListNode*fast=head;
        while(fast) {
            fast=fast->next->next; // because the length is even, fast must finally be nullptr; therefore the condition should be fast != nullptr rather than fast->next != nullptr
            ListNode*tmp=slow_curr->next;
            slow_curr->next=slow_prev;
            slow_prev=slow_curr;
            slow_curr=tmp;
        }
        int ans=0;
        while(slow_curr) {
            // slow_curr is now the head of the second half, and slow_prev is the head of the first half
            ans=max(ans,slow_curr->val+slow_prev->val);
            slow_curr=slow_curr->next;
            slow_prev=slow_prev->next;
        }
        return ans;
    }
};
```

This not only improves the space complexity, but also avoids pointers traversing the same path repeatedly.

[3379. Transformed Array - LeetCode](https://leetcode.cn/problems/transformed-array/description/?envType=daily-question&envId=2026-02-05)

Video explanation: https://t.bilibili.com/1166681192552988677?share_source=pc_native

You are given an integer array `nums`, which represents a circular array. Follow the rules below to create a new array `result` of the **same size**:

For each index `i` (`0 <= i < nums.length`), perform the following operation independently:

- If `nums[i] > 0`: starting from index `i`, move **right** by `nums[i]` steps. Assign the value at the landing index in the circular array to `result[i]`.
- If `nums[i] < 0`: starting from index `i`, move **left** by `abs(nums[i])` steps. Assign the value at the landing index in the circular array to `result[i]`.
- If `nums[i] == 0`: assign the value of `nums[i]` to `result[i]`.

Return the new array `result`.

**Note:** Since `nums` is a circular array, moving right past the last element returns to the beginning, and moving left past the first element returns to the end.

**Example 1:**

**Input:** nums = [3,-2,1,1]

**Output:** [1,1,1,3]

**Explanation:**

- For `nums[0] = 3`, move right 3 steps to `nums[3]`, so `result[0]` is 1.
- For `nums[1] = -2`, move left 2 steps to `nums[3]`, so `result[1]` is 1.
- For `nums[2] = 1`, move right 1 step to `nums[3]`, so `result[2]` is 1.
- For `nums[3] = 1`, move right 1 step to `nums[0]`, so `result[3]` is 3.

**Example 2:**

**Input:** nums = [-1,4,-1]

**Output:** [-1,-1,4]

**Explanation:**

- For `nums[0] = -1`, move left 1 step to `nums[2]`, so `result[0]` is -1.
- For `nums[1] = 4`, move right 4 steps to `nums[2]`, so `result[1]` is -1.
- For `nums[2] = -1`, move left 1 step to `nums[1]`, so `result[2]` is 4.

**Constraints:**

- `1 <= nums.length <= 100`
- `-100 <= nums[i] <= 100`

Let us first set aside the requirement that array indices must be non-negative, and regard `nums` as a circular array extending infinitely in both directions. The statement says that if `nums[i] < 0`, move left by `abs(nums[i])` positions, so the index after moving left is `i - abs(nums[i])`, which is `i + nums[i]`.

In other words, whether `nums[i]` is positive or negative, the index after moving is `i + nums[i]`. However, `i + nums[i]` may be greater than or equal to the array length or less than 0. For example, when the array length is 4, indices 1, 5, 9 and indices -3, -7, -11 correspond to the same value. We call them equivalent indices here.

Simplifying the problem: for an array `nums` of length `m`, how do we find an index equivalent to `i + nums[i]` that is valid for `nums`?

$$
If\ (x-y)\ is\ a\ multiple\ of\ m,\ then\ (x-y)\mod m=0,\\
then\ x\equiv y \pmod m,\\
and\ x\ and\ y\ are\ called\ congruent\ modulo\ m\\
\\
Corollary: Given\ x,y\in\mathbb{Z},\ x\equiv y \pmod m\ is\ a\ necessary\ and\ sufficient\ condition\ for\ x\ and\ y\ to\ be\ two\ terms\ of\ an\ arithmetic\ sequence\ with\ common\ difference\ m\\
Proof:\\
Sufficiency: because\ x\equiv y \pmod m,\ x-y=km,\ where\ k\in\mathbb{Z}\\
That\ is,\ x\ and\ y\ differ\ by\ an\ integer\ number\ of\ m,\ so\ they\ are\ two\ terms\ of\ an\ arithmetic\ sequence\ with\ common\ difference\ m\\
Necessity: because\ x\ and\ y\ are\ two\ terms\ of\ an\ arithmetic\ sequence\ with\ common\ difference\ m,\ let\\
x=km+t,\\
y=pm+t,\\
where\ k,p,t\in\mathbb{Z},\\
then\ x-y=(k-p)m.\ Since\ k-p\in\mathbb{Z},\ the\ proof\ is\ complete.\\
\\
Q: Given\ x\equiv y \pmod m,\ 0\leq y <m,\ and\ m>0,\ how\ can\ we\ adjust\ x\ to\ y?\\
\\
A: The\ case\ x>0\ is\ relatively\ simple; taking\ the\ remainder\ modulo\ m\ directly\ gives\ y.\ Consider\ x<0:\ since\ x\ and\ y\ are\ congruent\ modulo\ m,\ they\ differ\ by\ k\ multiples\ of\ m,\ where\ k\in\mathbb{Z}.\\
That\ is,\ x+km=y.\ First\ adjust\ x\ into\ the\ interval\ [-m+1,0],\\
let\ x'=x+(k-1)m.\ Since\ x+km=y\ and\ 0\leq y<m,\ by\ the\ definition\ of\ remainder,\ x'=x\mod m,\\
y-x'=m,\ so\ y=x\mod m+m\\
In\ summary,\ if\ x>0,\ then\ y=x\mod m;\ if\ x<0,\ then\ y=x\mod m +m,\ namely:\\
regardless\ of\ the\ sign\ of\ x,\ y=(x\mod m+m)\mod m
$$

As can be seen, to adjust `x` to `y`, we only need to take the modulo `m`, add `m`, and then take the modulo `m` for the whole expression.

Java

```java
class Solution {
    public int[] constructTransformedArray(int[] nums) {
        int m = nums.length;
        int[] res = new int[m];
        for(int i=0;i<m;i++) {
            res[i] = nums[((i + nums[i]) % m + m) % m];
        }
        return res;
    }
}
```

Go

```go
func constructTransformedArray(nums []int) []int {
    m := len(nums)
    res := make([]int,m)
    for i,v := range nums {
        res[i] = nums[((i + v) % m + m) % m]
    }
    return res
}
```

Python

```python
class Solution:
    def constructTransformedArray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        return [nums[(i + v) % n] for i, v in enumerate(nums)]
```

[73. Set Matrix Zeroes - LeetCode](https://leetcode.cn/problems/set-matrix-zeroes/description/?envType=study-plan-v2&envId=top-100-liked)

Given an `m x n` matrix, if an element is **0**, set all elements in its row and column to **0**. Use an **[in-place](http://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)** algorithm.

**Example 1:**

![](https://assets.leetcode.com/uploads/2020/08/17/mat1.jpg)

**Input:** matrix = `[[1,1,1],[1,0,1],[1,1,1]]`
**Output:** `[[1,0,1],[0,0,0],[1,0,1]]`

**Example 2:**

![](https://assets.leetcode.com/uploads/2020/08/17/mat2.jpg)

**Input:** matrix = `[[0,1,2,0],[3,4,5,2],[1,3,1,5]]`
**Output:** `[[0,0,0,0],[0,4,5,0],[0,3,1,0]]`

**Constraints:**

- `m == matrix.length`
- `n == matrix[0].length`
- `1 <= m, n <= 200`
- `-231 <= matrix[i][j] <= 231 - 1`

**Follow-up:**

- An intuitive solution uses `O(mn)` extra space, but this is not a good solution.
- A simple improvement uses `O(m + n)` extra space, but this is still not the best solution.
- Can you devise a solution that uses only constant space?

### Method 1: Brute Force (Not In-Place)

Traverse the array directly. When a 0 is encountered, traverse its row and column separately.

The problem is that after encountering a 0, all elements in its row and column are set to 0. Later, when traversing a cell that was originally 1 but has been set to 0, we may incorrectly determine that the cell was originally 0 and then incorrectly set the row and column containing that cell to 0.

The solution is to use a `flag` array to record the original state of `matrix`. In the `if` condition, simply check whether the corresponding position in `flag` is 0.

Code:
```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int row = matrix.length;
        int col = matrix[0].length;
        int[][] flag = new int[row][];
        for(int i=0;i<row;i++) {
            flag[i] = matrix[i].clone();
        }
        for(int i=0;i<row;i++) {
            for(int j=0;j<col;j++) {
                if(flag[i][j] == 0) {
                    for(int m=0;m<col;m++) {
                        matrix[i][m] = 0;
                    }
                    for(int n=0;n<row;n++) {
                        matrix[n][j] = 0;
                    }
                }
            }
        }
    }
}
```

Because of time constraints, I did not write Go, Python, or C++ versions. Most subsequent articles mainly contain Java, Go, and Python versions.

Time complexity:
- Best case: the matrix consists entirely of 1s, `O(mn)`.
- Worst case: the matrix consists entirely of 0s, `O(mn(m+n))`.
- Here, `m` and `n` are the number of rows and columns of the matrix.

### Method 2: Use Extra Arrays to Record Whether a Row/Column Contains 0 (Not In-Place)

Use a Boolean array `rowHasZero[]` of length `row` to record whether row `i` contains 0. If it does, set `rowHasZero[i] = true`.

Do the same for columns.

After determining which rows and columns contain 0, traverse `matrix` again. If `rowHasZero` or `colHasZero` is true, set all elements in that row or column to 0.

```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int row = matrix.length;
        int col = matrix[0].length;
        boolean rowHasZero[] = new boolean[row];
        boolean colHasZero[] = new boolean[col];
        for(int i=0;i<row;i++) {
            for(int j=0;j<col;j++) {
                if(matrix[i][j] == 0) {
                    rowHasZero[i] = true;
                    colHasZero[j] = true;
                }
            }
        }

        for(int i=0;i<row;i++) {
            for(int j=0;j<col;j++) {
                if(rowHasZero[i] || colHasZero[j]) {
                    matrix[i][j] = 0;
                }
            }
        }
    }
}
```

### Method 3: Use the Row/Column Headers Instead of Two HasZero Arrays (In-Place)

If a row contains 0, mark its row header as 0. When setting elements to 0 later, use the row header to determine whether the entire row should be set to 0. Do the same for columns.

Consider the problem with a matrix whose first row consists entirely of 1s and whose first column contains 0:

```
1 1 1
1 1 1
0 1 1
```

After determining the rows and columns, it becomes:

```
0 1 1
1 1 1
0 1 1
```

When we now start setting elements to 0, we may incorrectly determine that the first row contains 0. Since `(0,0)` is the intersection of the first row and first column, we cannot determine whether this 0 means the row or the column should be set to 0. Therefore, the first row and first column need two separate Boolean variables to determine whether they contain 0, and they are processed separately at the end.

```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int row = matrix.length;
        int col = matrix[0].length;
        // use the row and column headers to record whether they contain 0
        boolean firstRowHasZero = false;
        boolean firstColHasZero = false;
        for(int x : matrix[0]) {
            if(x == 0) {
                firstRowHasZero = true;
                break;
            }
        }
        for(int i=0;i<row;i++) {
            if(matrix[i][0] == 0) {
                firstColHasZero = true;
                break;
            }
        }

        for(int i=1;i<row;i++) {
            for(int j=1;j<col;j++) {
                if(matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        for(int i=1;i<row;i++) {
            for(int j=1;j<col;j++) {
                if(matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }

        if(firstRowHasZero) {
            Arrays.fill(matrix[0],0);
        }
        if(firstColHasZero) {
            for(int[] r : matrix) {
                r[0] = 0;
            }
        }
    }
}
```

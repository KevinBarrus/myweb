[105. Construct Binary Tree from Preorder and Inorder Traversal - LeetCode](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/description/?envType=study-plan-v2&envId=top-100-liked)

Given two integer arrays `preorder` and `inorder`, where `preorder` is the **preorder traversal** of a binary tree and `inorder` is the **inorder traversal** of the same tree, construct the binary tree and return its root node.

**Example 1:**

![](https://assets.leetcode.com/uploads/2021/02/19/tree.jpg)

**Input:** preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
**Output:** [3,9,20,null,null,15,7]

**Example 2:**

**Input:** preorder = [-1], inorder = [-1]
**Output:** [-1]

**Constraints:**

- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` and `inorder` contain **no duplicate** elements
- Every element in `inorder` also appears in `preorder`
- `preorder` is **guaranteed** to be the preorder traversal of a binary tree
- `inorder` is **guaranteed** to be the inorder traversal of a binary tree

### Method 1: Recursion

A key piece of information in this problem is that neither sequence contains duplicate elements.

The first element of a preorder traversal must be the root node, so we can locate the root in the inorder traversal. The result of an inorder traversal must be: the inorder traversal of the left subtree, the root node, and the inorder traversal of the right subtree. Since the preorder and inorder traversal sequences have the same length, we can obtain the preorder and inorder traversal sequences of the left and right subtrees.

Using recursion, construct the left and right subtrees, then connect the roots of the two subtrees to the left and right sides of the root of the whole tree.

There is one issue: each recursive call first needs to find the root node from the preorder traversal, and then locate its position in the inorder traversal. This process takes `O(n)` time.

Before construction begins, we can use a hash table to record the position of each node in the inorder traversal. The key is the value of the node, since the values are unique, and the value is the position where the node appears in the inorder traversal. This way, we only need to traverse the inorder sequence once, and subsequent recursive calls can locate each root in `O(1)` time.

```python
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
            def func(preorder_left: int, preorder_right: int, inorder_left: int, inorder_right: int):
                # recursive termination condition
                if preorder_left > preorder_right:
                    return None

                # the first node in preorder traversal is the root node
                root_pre = preorder_left

                # construct the root node
                root = TreeNode(preorder[root_pre])

                # locate the root index in inorder traversal
                inorder_root = index[preorder[root_pre]]

                # number of root nodes in the left subtree
                left_subTree_size = inorder_root - inorder_left

                # recursively construct the left subtree. Its preorder sequence starts at index 1 of preorder and contains left_subTree_size elements
                root.left = func(preorder_left + 1, preorder_left + left_subTree_size, inorder_left, inorder_root - 1)

                # the right subtree follows the same logic
                root.right = func(preorder_left + left_subTree_size + 1, preorder_right, inorder_root + 1, inorder_right)

                return root

            n = len(preorder)
            index = {element: i for i, element in enumerate(inorder)}
            return func(0, n - 1, 0, n - 1)
```

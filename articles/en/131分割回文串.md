[131. Palindrome Partitioning - LeetCode](https://leetcode.cn/problems/palindrome-partitioning/description/?envType=study-plan-v2&envId=top-100-liked)

Given a string `s`, partition `s` into some substrings such that every substring is a **palindrome**. Return **all possible partitionings** of `s`.

**Example 1:**

**Input:** s = "aab"
**Output:** `[ ["a","a","b"],["aa","b"] ]`

**Example 2:**

**Input:** s = "a"
**Output:** `[["a"]]`

**Constraints:**

- `1 <= s.length <= 16`
- `s` consists only of lowercase English letters

If a cut has already been made at a position, then we only need to consider how to cut the substring after that position. This is somewhat like the idea of a “problem and subproblem”. We can write a `dfs` function, where `dfs(i)` means that the unpartitioned part of string `s` starts at index `i` and continues to the end of the string. Then the recursion termination condition is `i == n`.

Next, consider the substring `[i, n - 1]`. Where should it be cut? Clearly, we must enumerate every position starting from `i` and check whether position `j` can form a palindrome with the starting position `i`. If not, continue enumerating; if so, add this palindrome to the answer, and then start searching for palindromes from `j + 1`, that is, call `dfs(j + 1)`. After `dfs(j + 1)` returns, remove the result added to the answer this time (because repeated calls to `dfs` will necessarily reach `i == n`, at which point `path` will be added to `ans`), and then continue the loop.

In other words, the recursive calls to `dfs` control how many cuts are made. The deeper the recursion, the more cuts are made, because each cut is made after the cuts that have already been made. The iteration controls where to cut: with the current number of cuts fixed, it searches forward for the cutting position.

```python
from typing import List

def partition(s: str) -> List[List[str]]:
    ans = []
    path = []
    n = len(s)

    def dfs(i: int) -> None:
        # dfs(i) means that the unpartitioned part of s is [i,n - 1]
        if i == n:
            # We cannot use ans.append("".join(path)), otherwise we cannot pop
            ans.append(path.copy())
            return
        # Enumerate the endpoint
        for j in range(i, n):
            substr = s[i: j + 1] # Extract the substring
            if substr == substr[::-1]:
                # If it is a palindrome
                path.append(substr)
                dfs(j + 1) # Start searching for a new substring after the current palindrome
                path.pop() # Restore the state
    dfs(0)
    return ans

def main():
    with open("case.txt", "r") as f:
        ss = f.read().split()

    for s in ss:
        result = partition(s)
        print(f"s = {s}")
        print(result)
        print()

if __name__ == "__main__":
    main()
```

Given two words `word1` and `word2`, _return the minimum number of operations required to convert `word1` into `word2`_.

You can perform the following three operations on a word:

- Insert a character.
- Delete a character.
- Replace a character.

**Example 1:**

**Input:** word1 = "horse", word2 = "ros"
**Output:** 3
**Explanation:**
horse -> rorse (replace 'h' with 'r')
rorse -> rose (delete 'r')
rose -> ros (delete 'e')

**Example 2:**

**Input:** word1 = "intention", word2 = "execution"
**Output:** 5
**Explanation:**
intention -> inention (delete 't')
inention -> enention (replace 'i' with 'e')
enention -> exention (replace 'n' with 'x')
exention -> exection (replace 'n' with 'c')
exection -> execution (insert 'u')

**Constraints:**

- `0 <= word1.length, word2.length <= 500`
- `word1` and `word2` consist of lowercase English letters.

Let `dp[i][j]` represent the edit distance, or minimum number of operations, required to convert the first `i` characters of `word1` into the first `j` characters of `word2`.

There are two cases: the characters are equal or they are not equal.

### Case 1: Equal Characters

If the `i`th character `word1[i - 1]` of `word1` equals the `j`th character `word2[j - 1]` of `word2`, no editing operation is needed, so `dp[i][j] = dp[i - 1][j - 1]`.

### Case 2: Unequal Characters

Consider the three editing operations:

#### Replacement

Replace `word1[i - 1]` with `word2[j - 1]`. The last characters are now equal, so add one operation: `dp[i][j] = dp[i - 1][j - 1] + 1`.

#### Insertion

Insert `word2[j - 1]` into `word1`. The length of `word1` becomes `i + 1`, which is equivalent to converting the first `i` characters of `word1` into the first `j - 1` characters of `word2`, and then inserting one character: `dp[i][j] = dp[i][j - 1] + 1`.

#### Deletion

Delete `word1[i - 1]` from `word1`. The length of `word1` becomes `i - 1`, which is equivalent to converting the first `i - 1` characters of `word1` into the first `j` characters of `word2`: `dp[i][j] = dp[i - 1][j] + 1`.

Finally, take the minimum of these three cases.

### Boundary Cases

If one string is empty and the other is non-empty with length `k`, simply perform `k` deletion or insertion operations.

Therefore, `dp[i][0] = i, dp[0][j] = j`.

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int n = word1.length();
        int m = word2.length();
        if(n * m == 0) {
            // if one string is empty, only n or m deletion or insertion operations are needed
            return n + m;
        }

        int[][] dp = new int[n + 1][m + 1];
        for(int i = 0; i < n + 1; i++) {
            dp[i][0] = i;
        }
        for(int j = 0; j < m + 1; j++) {
            dp[0][j] = j;
        }

        for(int i = 1; i < n + 1; i++) {
            for(int j = 1; j < m + 1; j++) {
                if(word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = Math.min(dp[i - 1][j],
                        Math.min(dp[i][j - 1],dp[i - 1][j - 1])
                    ) + 1;
                }
            }
        }
        return dp[n][m];
    }
}
```

The `dp` array can be simplified to a two-row array, because `dp[i][j]` only relates to the elements at its upper-left, left, and upper positions.

It can be simplified further to a one-dimensional array.

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word2.length();
        char[] w2 = word2.toCharArray();

        int[] dp = new int[m + 1];
        for(int j = 0; j < m; j++) {
            // dp[0] is equivalent to dp[i][0], whose value is i, so do not initialize it here; process it while traversing word1
            dp[j + 1] = j + 1;
        }

        for(char ch : word1.toCharArray()) {
            int pre = dp[0]; // when j = 0, the upper-left of dp[i][1] is dp[i - 1][0]
            dp[0]++; // for every word1[i - 1] traversed, dp[i][0] becomes i; in a one-dimensional array, incrementing gives i
            for(int j = 0; j < m; j++) {
                int tmp = dp[j + 1];
                if(ch == w2[j]) {
                    dp[j + 1] = pre;
                } else {
                    // pre is the upper-left value, dp[j + 1] is the upper value, and dp[j] is the left value
                    dp[j + 1] = Math.min(Math.min(dp[j + 1], dp[j]), pre) + 1;
                }
                pre = tmp;
            }
        }

        return dp[m];
    }
}
```

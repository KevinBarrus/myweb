Problem link: [178. Rank Scores - LeetCode](https://leetcode.cn/problems/rank-scores/?envType=problem-list-v2&envId=database)

Table: `Scores`

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| score       | decimal |
+-------------+---------+
id is the primary key of this table (a column with unique values).
Each row of this table contains the score of a game. Score is a floating-point value with two decimal places.
```

Write a solution to query the ranking of the scores. The ranking is calculated according to the following rules:

- Scores should be ranked from highest to lowest.
- If two scores are equal, they should have the same rank.
- After scores with the same rank, the next rank should be the next consecutive integer. In other words, there should be no gaps between ranking numbers.

Return the result table ordered by `score` in descending order.

The query result format is shown below.

**Example 1:**

```
Input:
Scores table:
+----+-------+
| id | score |
+----+-------+
| 1  | 3.50  |
| 2  | 3.65  |
| 3  | 4.00  |
| 4  | 3.85  |
| 5  | 4.00  |
| 6  | 3.65  |
+----+-------+
Output:
+-------+------+
| score | rank |
+-------+------+
| 4.00  | 1    |
| 4.00  | 1    |
| 3.85  | 2    |
| 3.65  | 3    |
| 3.65  | 3    |
| 3.50  | 4    |
+-------+------+
```

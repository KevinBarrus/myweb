[39. Combination Sum - LeetCode](https://leetcode.cn/problems/combination-sum/description/?envType=study-plan-v2&envId=top-100-liked)

Given an array `candidates` of **distinct** integers and a target integer `target`, return a list of all **distinct combinations** of `candidates` whose sum equals `target`. You may return the combinations in **any order**.

The **same** number may be chosen from `candidates an unlimited number of times`. Two combinations are different if the frequency of at least one chosen number is different.

For the given input, the number of distinct combinations that sum to `target` is guaranteed to be fewer than `150`.

**Example 1:**

**Input:** candidates = [2,3,6,7], target = 7
**Output:** `[[2,2,3],[7]]`
**Explanation:**
2 and 3 can form one combination: 2 + 2 + 3 = 7. Note that 2 can be used multiple times.
7 is also a candidate, and 7 = 7.
There are only these two combinations.

**Example 2:**

**Input:** candidates = [2,3,5], target = 8
**Output:** `[[2,2,2,2],[2,3,3],[3,5]]`

**Example 3:**

**Input:** candidates = [2], target = 1
**Output:** []

**Constraints:**

- `1 <= candidates.length <= 30`
- `2 <= candidates[i] <= 40`
- All elements in `candidates` are **distinct**.
- `1 <= target <= 40`

Suppose the length of `candidates` is `n`. It can be regarded as an `n`-ary tree, and we can perform DFS on this tree. Whenever we reach a node, compare the sum of the current path with `target`: backtrack if it is greater than `target`, add the node values in the current path directly to the answer if it equals `target`, and continue searching downward if it is smaller. Therefore, it is not difficult to see that sorting `candidates` in advance can avoid many unnecessary traversals. If adding a small number to the current path already makes the sum greater than `target`, there is no need to consider adding numbers larger than it.

However, note that `[2, 2, 3]` and `[3, 2, 2]` are the same combination. This means we cannot simply regard the structure as an `n`-ary tree; some branches must be pruned. In Example 1, for 2, we can choose 2, 3, 6, or 7. For 3, there is no need to choose 2, because `[2, 3]` and `[3, 2]` are the same combination, so 3 only needs to choose one of 3, 6, or 7. Similarly, for 6, it only needs to choose 6 or 7.

In other words, we need a variable `start`, indicating that `candidates[start]` and all numbers after it are available for selection. Pass this variable as a parameter of the recursion.

```python
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        candidates.sort()
        ans = []

        def backtrack(start: int, path: List[int], remain: int) -> None:
            # remain represents how much is still needed to reach target
            if remain == 0:
                ans.append(path[:])
                return
            if remain < 0:
                return

            for i in range(start, len(candidates)):
                if candidates[i] > remain:
                    # if adding the current element exceeds target, this path cannot work
                    break
                path.append(candidates[i])
                backtrack(i, path, remain - candidates[i])
                path.pop()

        backtrack(0, [], target)
        return ans
```

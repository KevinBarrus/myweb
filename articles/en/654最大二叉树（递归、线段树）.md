### 654 Maximum Binary Tree: Recursion

Problem link: [654. Maximum Binary Tree - LeetCode](https://leetcode.cn/problems/maximum-binary-tree/description/)

Given an integer array `nums` with no duplicate values, a **maximum binary tree** can be recursively constructed from `nums` using the following algorithm:

1. Create a root node whose value is the maximum value in `nums`.
2. Recursively construct the left subtree on the **prefix subarray** to the **left** of the maximum value.
3. Recursively construct the right subtree on the **suffix subarray** to the **right** of the maximum value.

Return the **maximum binary tree** constructed from *`nums`*.

**Example 1:**

![img](https://assets.leetcode.com/uploads/2020/12/24/tree1.jpg)

```
Input: nums = [3,2,1,6,0,5]
Output: [6,3,5,null,2,0,null,null,1]
Explanation: The recursive calls are as follows:
- The maximum value in [3,2,1,6,0,5] is 6; the left part is [3,2,1] and the right part is [0,5].
    - The maximum value in [3,2,1] is 3; the left part is [] and the right part is [2,1].
        - Empty array, no child nodes.
        - The maximum value in [2,1] is 2; the left part is [] and the right part is [1].
            - Empty array, no child nodes.
            - There is only one element, so the child is a node whose value is 1.
    - The maximum value in [0,5] is 5; the left part is [0] and the right part is [].
        - There is only one element, so the child is a node whose value is 0.
        - Empty array, no child nodes.
```

**Example 2:**

![img](https://assets.leetcode.com/uploads/2020/12/24/tree2.jpg)

```
Input: nums = [3,2,1]
Output: [3,null,2,null,1]
```

**Constraints:**

- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`
- All integers in `nums` are **distinct**.

Recursion is the obvious approach. In each subproblem, the task is simple: find the maximum value in a certain interval of the array, create a node whose value is this maximum, and then find the maximum value in the array to the left and to the right of this maximum. At this point, the idea is clear: this is a repeated problem of finding the maximum value within a given interval.

Recursive function:

```c++
    // find the maximum value in [left,right), construct the root node, and recurse
    TreeNode* f(vector<int>&nums,int left,int right) {
        // construct the binary tree over [left,right), closed on the left and open on the right
        // first check the termination condition
        if(left>=right) return nullptr;
        // find the root index to determine the split point
        int maxval_index=left;
        for(size_t i=left;i<right;i++) {
            if(nums[i]>nums[maxval_index]) {
                maxval_index=i;
            }
        }
        // construct the root node
        TreeNode* root=new TreeNode(nums[maxval_index]);

        // its left child is the maximum value in the array to its left, and the right child follows the same logic
        root->left=f(nums,left,maxval_index);

        root->right=f(nums,maxval_index+1,right);

        return root;
    }
```

Whether the interval is open or closed at either end does not matter.

The termination condition actually handles the case where the boundary element itself is the maximum. `return nullptr` guarantees that one side has no child node.

This avoids slicing the vector and constructing a new one.

Complete code:

```c++
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    // find the maximum value in [left,right), construct the root node, and recurse
    TreeNode* f(vector<int>&nums,int left,int right) {
        // construct the binary tree over [left,right), closed on the left and open on the right
        // first check the special case
        if(left>=right) return nullptr;
        // find the root index to determine the split point
        int maxval_index=left;
        for(size_t i=left;i<right;i++) {
            if(nums[i]>nums[maxval_index]) {
                maxval_index=i;
            }
        }
        // construct the root node
        TreeNode* root=new TreeNode(nums[maxval_index]);

        // its left child is the maximum value among the numbers to its left, and the right child follows the same logic
        root->left=f(nums,left,maxval_index);

        root->right=f(nums,maxval_index+1,right);

        return root;
    }
    TreeNode* constructMaximumBinaryTree(vector<int>& nums) {
        return f(nums,0,nums.size());
    }
};
```

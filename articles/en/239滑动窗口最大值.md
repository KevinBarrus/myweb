[239. Sliding Window Maximum - LeetCode](https://leetcode.cn/problems/sliding-window-maximum/description/?envType=study-plan-v2&envId=top-100-liked)

You are given an integer array `nums` and a sliding window of size `k` that moves from the very left of the array to the very right. You can only see the `k` numbers in the sliding window. The sliding window moves one position to the right each time.

Return the _maximum value in the sliding window_.

**Example 1:**

**Input:** nums = [1,3,-1,-3,5,3,6,7], k = 3
**Output:** [3,3,5,5,6,7]
**Explanation:**
Sliding window position          Maximum
----------------------           -------
[1  3  -1] -3  5  3  6  7        **3**
 1 [3  -1  -3] 5  3  6  7        **3**
 1  3 [-1  -3  5] 3  6  7       **5**
 1  3  -1 [-3  5  3] 6  7        **5**
 1  3  -1  -3 [5  3  6] 7        **6**
 1  3  -1  -3  5 [3  6  7]       **7**

**Example 2:**

**Input:** nums = [1], k = 1
**Output:** [1]

**Constraints:**

- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 104`
- `1 <= k <= nums.length`

Use a monotonic queue: elements enter from the right and leave from the left, while recording and maintaining the answer.

First, to conveniently record the element at the front leaving the window, the queue should store element indices.

How do we maintain monotonicity? If the value corresponding to the last element in the queue is no greater than the value of the element currently being traversed, continuously pop elements from the back of the queue. This ensures that the queue is monotonically decreasing; more precisely, the values corresponding to the positions stored in the queue are monotonically decreasing. Therefore, the index corresponding to the maximum value in the sliding window must be at the front. For example, in the second window of Example 1, when the window elements are `[3, -1, 3]` and the next element is 5, when traversing 5 we find that it is greater than the value corresponding to every element at the back of the monotonic queue, so the queue is cleared and index 4, corresponding to 5, is placed in the queue. This can be compared to a new employee who is stronger and younger: past employees who are weaker, or equally strong but older, should be optimized away. This is why the condition is “no greater than” rather than “less than”.

What if the maximum value leaves the sliding window? We only need to record the left endpoint `left` of the current sliding window during each traversal, and compare `q[0]` with `left`. If `q[0] < left`, the maximum value has left the window, so simply call `popleft()`. In other words, we only need to care whether the left-end element leaves the window when that element is the maximum value; if it is not the maximum, we do not need to care whether it leaves.

```python
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        ans = [0] * (len(nums) - k + 1)
        q = deque() # queue

        for i, v in enumerate(nums):
            # leave the queue when the tail value is no greater than the newly traversed value
            while q and nums[q[-1]] <= v:
                q.pop()
            q.append(i)

            # consider the oldest employee being dismissed, meaning the left endpoint leaves the window
            left = i - k + 1 # left endpoint of the sliding window
            if q[0] < left:
                # if the strongest employee has reached the dismissal age, pop it
                q.popleft()

            # record the maximum value of the current sliding window
            if left >= 0:
                # if a complete sliding window of length k has not formed, do not record an answer yet; this is why ans cannot initially be []
                ans[left] = nums[q[0]]

        return ans
```

The first element represents `k`, and all subsequent elements are elements of `nums`.

```python
from typing import List
from collections import deque

def maxSlidingWindow(nums: List[int], k: int) -> List[int]:
    ans = [0] * (len(nums) - k + 1)
    q = deque()

    for i, v in enumerate(nums):
        while q and nums[q[-1]] <= v:
            q.pop()
        q.append(i)

        left = i - k + 1
        if q[0] < left:
            q.popleft()
        if left >= 0:
            ans[left] = nums[q[0]]
    return ans

def main():
    with open("input.txt", "r") as f:
        data = f.read().split()
    k = int(data[0])
    nums = list(map(int, data[1:]))
    print(maxSlidingWindow(nums, k))

if __name__ == "__main__":
    main()
```

[148. Sort List - LeetCode](https://leetcode.cn/problems/sort-list/?envType=study-plan-v2&envId=top-100-liked)

Given the head node `head` of a linked list, sort it in **ascending order** and return the **sorted linked list**.

**Example 1:**

![](https://assets.leetcode.com/uploads/2020/09/14/sort_list_1.jpg)

**Input:** head = [4,2,1,3]
**Output:** [1,2,3,4]

**Example 2:**

![](https://assets.leetcode.com/uploads/2020/09/14/sort_list_2.jpg)

**Input:** head = [-1,5,3,4,0]
**Output:** [-1,0,3,4,5]

**Example 3:**

**Input:** head = []
**Output:** []

**Constraints:**

- The number of nodes in the linked list is in the range ` [0, 5 * 104]`
- `-105 <= Node.val <= 105`

**Follow-up:** Can you sort the linked list in `O(n log n)` time and `O(1)` space complexity?

### Method 1: Merge Sort (Recursive)

1. Find the node before the middle node `head2` of the linked list and disconnect `head2` from its previous node. The linked list is then split into two shorter linked lists. Recursively call `sortList` on these two lists to obtain the sorted `head` and `head2`, then merge the two sorted linked lists.

[21. Merge Two Sorted Lists - LeetCode](https://leetcode.cn/problems/merge-two-sorted-lists/description/?envType=study-plan-v2&envId=top-100-liked)

Clearly, use fast and slow pointers to find the middle node, and use two pointers to merge two sorted linked lists.

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if(head == null || head.next == null) {
            return head;
        }
        // find the middle node
        ListNode head2 = findMidNode(head);
        // divide and conquer
        head = sortList(head);
        head2 = sortList(head2);
        // merge
        return mergeTwoList(head, head2);
    }

    // use fast and slow pointers to find the middle node
    public ListNode findMidNode(ListNode head) {
        ListNode pre = head; // record the node before slow for the later split
        ListNode slow = head;
        ListNode fast = head;
        while(fast != null && fast.next != null) {
            pre = slow;
            slow = slow.next;
            fast = fast.next.next;
        }
        pre.next = null; // disconnect
        return slow; // return the second half; the head of the first half is already known as head
    }

    // use two pointers to merge two linked lists
    public ListNode mergeTwoList(ListNode head1, ListNode head2) {
        ListNode dummy = new ListNode();
        ListNode cur = dummy; // cur points to the end of the new list
        while(head1 != null && head2 != null) {
            if(head1.val < head2.val) {
                cur.next = head1;
                head1 = head1.next;
            } else {
                cur.next = head2;
                head2 = head2.next;
            }
            cur = cur.next;
        }
        cur.next = head1 != null ? head1 : head2; // append the remaining list
        return dummy.next;
    }
}
```

The recursion depth is `O(log n)`, so the space complexity is `O(log n)`.

Since the sum of the linked-list lengths at each level is `O(n)`, the time complexity is `O(nlogn)`.

### Method 2: Merge Sort (Iterative)

Reverse the recursive process from Method 1 and handle it iteratively to eliminate the recursion stack overhead.

In the recursive method, we split the linked list into 2, 4, 8, ... parts until each part has only one node, and then merge them. Now process from the bottom up:

1. Merge sublists of length 1: merge the first and second nodes and put them at the end of the linked list, then merge the third and fourth nodes and put them at the end, continuing until the entire list has been traversed. Therefore, the length of the linked list must be known in advance. At this point, every pair of nodes is ordered.

2. Merge sublists of length 2: merge the first and second groups of nodes, with two nodes in each group, and put them at the end of the linked list. Then merge the third and fourth groups and put them at the end, continuing until the entire list has been traversed. At this point, every four nodes are ordered.

3. The lengths of the sublists to merge form a geometric sequence with first term 1 and common ratio 2.

4. Continue until the length of the sublists to merge is no less than the length of the linked list.

```python
class Solution:
    # get the linked-list length
    def getListLength(self, head : Optional[ListNode]) -> int :
        length = 0
        while head :
            length += 1
            head = head.next
        return length

    # split the linked list
    def splitList(self, head : Optional[ListNode], size : int) -> Optional[ListNode] :
        # try to find the node before the head of the next group
        cur = head
        for _ in range(size - 1) : # loop size - 1 times; cur finally points to the size-th node, if it exists
            if cur is None :
                break
            cur = cur.next

        # if the linked-list length <= size
        if cur is None or cur.next is None :
            return None # no split is needed

        next_head = cur.next
        cur.next = None # disconnect the groups
        return next_head # return the head of the next group; the current group's head is already known as head

    # merge two sorted linked lists. Since this is bottom-up, return the head and tail of the merged list
    def mergeTwoLists(self, list1 : Optional[ListNode], list2 : Optional[ListNode]) -> Optional[ListNode] :
        cur = dummy = ListNode() # sentinel dummy; cur points to the tail of the new list
        while list1 and list2 :
            if list1.val < list2.val :
                cur.next = list1
                list1 = list1.next
            else :
                cur.next = list2
                list2 = list2.next
            cur = cur.next
        cur.next = list1 or list2 # append the remaining list

        # get the tail node
        while cur.next :
            cur = cur.next
        return dummy.next, cur

    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode] :
        length = self.getListLength(head)
        dummy = ListNode(next = head) # the head may change, so use a dummy head to simplify the logic
        step = 1 # length of the sublists to merge
        while step < length :
            cur = dummy.next # starting node of this round
            list_tail = dummy # tail of the new list
            while cur :
                # starting at cur, split out two sublists of length step, merge them, and append them to the list
                head1 = cur
                head2 = self.splitList(head1, step)
                cur = self.splitList(head2, step) # starting node of the next round

                # merge two sublists of length step
                head, tail = self.mergeTwoLists(head1, head2)

                # put the merged head head after the current list tail
                list_tail.next = head
                list_tail = tail # tail is now the end of the whole list
            step *= 2
        return dummy.next
```

[160. Intersection of Two Linked Lists - LeetCode](https://leetcode.cn/problems/intersection-of-two-linked-lists/description/?envType=study-plan-v2&envId=top-100-liked)

Given the head nodes `headA` and `headB` of two singly linked lists, find and return the starting node where the two linked lists intersect. If the two linked lists do not intersect, return `null`.

The two linked lists intersect at node **c1**:

[![img](https://assets.leetcode-cn.com/aliyun-lc-upload/uploads/2018/12/14/160_statement.png)](https://assets.leetcode-cn.com/aliyun-lc-upload/uploads/2018/12/14/160_statement.png)

The test data **guarantees** that there is no cycle in the entire linked structure.

**Note:** After the function returns, the linked lists must **retain their original structure**.

**Custom Judge:**

The input to the **evaluation system** is as follows (the program you design does **not apply** to this input):

- `intersectVal` - the value of the node at which the lists intersect. If there is no intersection, this value is `0`.
- `listA` - the first linked list.
- `listB` - the second linked list.
- `skipA` - the number of nodes to skip from the head of `listA` to reach the intersection node.
- `skipB` - the number of nodes to skip from the head of `listB` to reach the intersection node.

The evaluation system creates the linked structure according to these inputs and passes the two head nodes `headA` and `headB` to your program. If the program can correctly return the intersection node, your solution will be **considered correct**.

**Constraints:**

- The number of nodes in `listA` is `m`.
- The number of nodes in `listB` is `n`.
- `1 <= m, n <= 3 * 104`
- `1 <= Node.val <= 105`
- `0 <= skipA <= m`
- `0 <= skipB <= n`
- If `listA` and `listB` have no intersection, `intersectVal` is `0`.
- If `listA` and `listB` have an intersection, `intersectVal == listA[skipA] == listB[skipB]`.

**Follow-up:** Can you design a solution with `O(m + n)` time complexity and only `O(1)` memory?

Method 1: Set

Traverse either linked list and add the nodes to a set while traversing. Then traverse the other linked list. Once a node is found to already exist in the set, that node must be the intersection node.

C++

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        unordered_set<ListNode*>s;
        while(headA) {
            s.insert(headA);
            headA=headA->next;
        }
        while(headB) {
            if(s.find(headB)!=s.end()) {
                return headB;
            }
            headB=headB->next;
        }
        return nullptr;
    }
};
```

Java

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        Set<ListNode>s = new HashSet<ListNode>();
        ListNode temp=headA;
        while(temp!=null) {
            s.add(temp);
            temp=temp.next;
        }
        temp=headB;
        while(temp!=null) {
            if(s.contains(temp)) {
                return temp;
            }
            temp=temp.next;
        }
        return null;
    }
}
```

Go

```go

 * Definition for singly-linked list.

 *     Val int
 *     Next *ListNode
 * }

func getIntersectionNode(headA, headB *ListNode) *ListNode {
    mp:=map[*ListNode]bool{}
    for temp:=headA;temp!=nil;temp=temp.Next {
        mp[temp]=true
    }
    for temp:=headB;temp!=nil;temp=temp.Next {
        if(mp[temp]) {
            return temp
        }
    }
    return nil
}
```

Method 2: Walk the road you walked, only to meet you

A first traverses 200, then 400, and finally 800, while B first traverses 400, then 200, and finally 800. These are equivalent. As long as A and B move at the same speed, they must meet after traversing the first 600.

Assume the pointer traversing list A is named `a`, and the pointer traversing list B is named `b`. We only need to let `a` and `b` each traverse their linked list. When a pointer reaches the last node, jump it back to the beginning of the other linked list, which is equivalent to traversing the distance covered by the other pointer. Thus, if the linked lists intersect, the two pointers must meet at the intersection.

C++

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        ListNode* a=headA;
        ListNode* b=headB;
        while(a!=b) {
            a= a==nullptr?headB:a->next;
            b= b==nullptr?headA:b->next;
        }
        return a;
    }
};
```

Go

```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func getIntersectionNode(headA, headB *ListNode) *ListNode {
    a:=headA
    b:=headB
    for a!=b {
        if(a==nil) {
            a=headB
        } else {
            a=a.Next
        }
        if(b==nil) {
            b=headA
        } else {
            b=b.Next
        }
    }
    return a
}
```

What if the two linked lists do not intersect? If they do not intersect, `a` traverses list B while `b` traverses list A. Both become empty, so the `while` loop exits and `null` is ultimately returned.

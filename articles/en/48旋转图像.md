Given an `n` × `n` 2D matrix `matrix` representing an image, rotate the image clockwise by 90 degrees.

You must rotate the image **[in place](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)**, which means directly modifying the input 2D matrix. **Do not** use another matrix to rotate the image.

**Example 1:**

![](https://assets.leetcode.com/uploads/2020/08/28/mat1.jpg)

**Input:** matrix = `[[1,2,3],[4,5,6],[7,8,9]]`
**Output:** `[[7,4,1],[8,5,2],[9,6,3]]`

**Example 2:**

![](https://assets.leetcode.com/uploads/2020/08/28/mat2.jpg)

**Input:** matrix = `[[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]`
**Output:** `[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]`

**Constraints:**

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

It is equivalent to a person viewed from the front becoming a person viewed from the right.

Suppose the original matrix has `n` rows and `n` columns.

The original column 0 becomes row 0 after rotation; the original column 1 becomes row 1; and the original column `j` becomes row `j`.

The original row 0 becomes column `n - 1` after rotation; the original row 1 becomes column `n - 2`; and the original row `i` becomes column `n - 1 - i`.

Therefore, the original `(i, j)` becomes `(j, n - 1 - i)` after rotation.

However, we cannot swap directly, because every element would necessarily be swapped twice, and two swaps are equivalent to no swap. The reason is that direct swapping lacks symmetry. With symmetry, we only need to traverse half of the array and perform each swap once.

`(i, j) -> (j, n - 1 - i)` can be regarded as:

`(i, j) -> (j, i) -> (j, n - 1 - i)`.

That is, first transpose the matrix, then flip it along the vertical center line.

Transposition is essentially flipping along the main diagonal, so it also has symmetry. Therefore, both operations are symmetric and can be implemented.

Java

```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;
        for (int i = 0; i < n; i++) {
            int[] row = matrix[i];
            // traverse elements above the diagonal and swap (i, j) -> (j, i), which transposes the matrix
            for(int j = i + 1; j < n; j++) {
                int tmp = row[j];
                row[j] = matrix[j][i];
                matrix[j][i] = tmp;
            }

            // traverse the left half and swap (j, i) -> (j, n - 1 - i), which flips along the vertical center line
            for(int j = 0; j < n / 2; j++) {
                int tmp = row[j];
                row[j] = row[n - 1 - j];
                row[n - 1 - j] = tmp;
            }
        }
    }
}
```

Here we must traverse the upper triangle rather than the lower triangle first. Take Example 1:

If the lower triangle is traversed:
`[1, 2, 3]` has no transposed elements; after flipping along the center line it becomes `[3, 2, 1]`.
`[4, 5, 6]` swaps 4 and 2, then becomes `[6, 5, 2]` after flipping along the center line.
`[7, 8, 9]` swaps 7 and 1, swaps 8 and 2, then becomes `[9, 2, 1]` after flipping along the center line.

The final result is:
```
[3, 4, 7]
[6, 5, 8]
[9, 2, 1]
```

The lower triangle performs the column transformation first and then the transposition, so the order is wrong.

The upper triangle guarantees that each row is transposed first and then transformed by columns.

Python

```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        n = len(matrix)
        for i, row in enumerate(matrix) :
            for j in range(i + 1, n) :
                row[j], matrix[j][i] = matrix[j][i], row[j]
            row.reverse() # reverse the row
```

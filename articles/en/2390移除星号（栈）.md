Problem link: [2390. Removing Stars From a String - LeetCode](https://leetcode.cn/problems/removing-stars-from-a-string/)

You are given a string `s` containing several asterisks `*`.

In one operation, you can:

- Choose an asterisk in `s`.
- Remove the closest **non-asterisk** character to the **left** of the asterisk, and remove the asterisk itself.

Return the string after removing **all** asterisks.

**Note:**

- The generated input always guarantees that the operation described in the statement can be performed.
- It can be proved that the resulting string is unique.

**Example 1:**

```
Input: s = "leet**cod*e"
Output: "lecoe"
Explanation: Perform the removal operations from left to right:
- The character closest to the first asterisk is 't' in "leet**cod*e", so s becomes "lee*cod*e".
- The character closest to the second asterisk is 'e' in "lee*cod*e", so s becomes "lecod*e".
- The character closest to the third asterisk is 'd' in "lecod*e", so s becomes "lecoe".
There are no other asterisks, so return "lecoe".
```

**Example 2:**

```
Input: s = "erase*****"
Output: ""
Explanation: The entire string is removed, so return the empty string.
```

**Constraints:**

- `1 <= s.length <= 105`
- `s` consists of lowercase English letters and asterisks `*`.
- `s` can undergo the operations described above.

This problem is relatively simple, and the simplest approach is direct simulation. Traverse the string: if the character is a letter, put it into a new string; if it is an asterisk, pop the last letter.

```c++
class Solution {
public:
    string removeStars(string s) {
        string ans;
        for(char ch:s) {
            if(ch=='*') {
                ans.pop_back();
            } else {
                ans+=ch;
            }
        }
        return ans;
    }
};
```

Go version:

```go
func removeStars(s string) string {
    var ans []rune
    for _,ch := range s {
        if ch != '*' {
            ans = append(ans,ch)
        } else {
            ans = ans[:len(ans)-1]
        }
    }
    return string(ans)
}
```

In fact, `string`/`vector` in C++ can both be used directly as stacks.

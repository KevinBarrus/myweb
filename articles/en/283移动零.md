[283. Move Zeroes - LeetCode](https://leetcode.cn/problems/move-zeroes/description/)

Given an array `nums`, write a function to move all `0`s to the end of the array while maintaining the relative order of the non-zero elements.

**Note:** You must operate on the array in place without making a copy of the array.

**Example 1:**

```
Input: nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
```

**Example 2:**

```
Input: nums = [0]
Output: [0]
```

**Constraints:**

- `1 <= nums.length <= 104`
- `-231 <= nums[i] <= 231 - 1`

**Follow-up:** Can you minimize the total number of operations done?

This is equivalent to moving all non-zero elements to the front of the array without changing their relative order. The most intuitive approach is to traverse the array and move a non-zero element forward whenever one is encountered. This raises a new question: where should it be moved? We need another variable to mark the destination. This resembles two pointers, so let the right pointer continuously search for non-zero elements. Once one is found, move it to the position of the left pointer. When the position of the left pointer contains a non-zero element, move the left pointer one position forward; otherwise it is occupying an empty slot. The purpose of the left pointer is to mark where the next non-zero element should be placed. Once its position is occupied, it should move forward.

Put more crudely, the right pointer is a blind person, and a non-zero element is like the excrement produced by the right pointer. The left pointer is its guide dog, telling the right pointer where to go. If a hole is already filled, the guide dog should move to the next empty hole so that the right pointer knows where to go next.

Note that overwriting differs from swapping. With overwriting, we must finally traverse from the left pointer `left` to the end of the array and assign 0 to every element encountered, because no swaps were performed. The reason to start from `left`, rather than `left + 1` or `left - 1`, is that `left` marks where the next non-zero element should be placed, and all non-zero elements have been moved before `left` at the end. Therefore, the empty holes from `left` onward must not remain filled with non-zero elements. If the array consists entirely of zeros, overwriting requires traversing the array twice, while swapping does not require this consideration.

Java:

```java
class Solution {
    public void moveZeroes(int[] nums) {
        // the right pointer keeps moving forward; when it encounters a non-zero element, move it forward
        // the destination is controlled by the left pointer: move it to the position of the left pointer
        int left=0,right=0,n=nums.length;
        while(right<n) {
            if(nums[right] != 0) {
                // swap
                int temp = nums[left];
                nums[left] = nums[right];
                nums[right] = temp;
                left++;
            }
            right++;
        }
        // with overwriting, an all-zero array would require traversing twice
    }
}
```

C++:

``` cpp
class Solution
{
public:
    void moveZeroes(vector<int>& nums)
    {
        int n = nums.size();
        int left = 0, right = 0;
        while (right < n)
        {
            if (nums[right])
            {
                swap(nums[left], nums[right]);
                left++;
            }
            right++;
        }
    }
};
```

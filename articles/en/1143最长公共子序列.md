Given two strings `text1` and `text2`, return the length of their longest **common subsequence**. If there is no **common subsequence**, return `0`.

A **subsequence** of a string is a new string formed by deleting some characters, or none, from the original string without changing the relative order of the remaining characters.

- For example, `"ace"` is a subsequence of `"abcde"`, but `"aec"` is not a subsequence of `"abcde"`.

A **common subsequence** of two strings is a subsequence that both strings share.

**Example 1:**

**Input:** text1 = "abcde", text2 = "ace"
**Output:** 3<br>
**Explanation:** The longest common subsequence is "ace", and its length is 3.

**Example 2:**

**Input:** text1 = "abc", text2 = "abc"
**Output:** 3
**Explanation:** The longest common subsequence is "abc", and its length is 3.

**Example 3:**

**Input:** text1 = "abc", text2 = "def"
**Output:** 0
**Explanation:** The two strings have no common subsequence, so 0 is returned.

**Constraints:**

- `1 <= text1.length, text2.length <= 1000`
- `text1` and `text2` consist only of lowercase English letters.

For subsequence problems, we generally set `dp[i]` to the length of the longest common subsequence in the part of the string from 0 to `i`.

There are two strings here, and we need their longest common subsequence. We can let `dp[i][j]` represent the length of the longest common subsequence of `text1[0:i]` and `text[0:j]`. Here, `text[0:k]` represents the substring formed by the elements from index 0 through index `k`.

First consider the recurrence. It is not difficult to see that the key is whether `text1[i]` and `text2[j]` are selected.

Whether to select them means checking whether their existence affects the length of the common subsequence. Clearly, if `text1[i]` equals `text2[j]`, the two characters can both contribute to “extending the longest common subsequence”, because they are part of a common subsequence. Therefore, we only need to look at the value of `dp[i-1][j-1]`, the length of the longest common subsequence of `text1[0:i-1]` and `text2[0:j-1]`. Thus:

`dp[i][j] = dp[i-1][j-1] + 1, text1[i] == text2[j]`

As in Example 1:

text1 = abcde
text2 = ace

When `i = 4` and `j = 2`, this is exactly the case described above.

What if `text[i]` is not equal to `text[j]`?

The two elements cannot contribute at the same time, so either `text1[i]` contributes or `text2[j]` contributes.

If `text1[i]` contributes, then `dp[i][j] = dp[i][j-1]`.

If `text2[j]` contributes, then `dp[i][j] = dp[i-1][j]`.

Since we need the longest subsequence, take the maximum of the two:

`dp[i][j] = max(dp[i-1][j], dp[i][j-1]), text1[i] != text2[j]`

One possible question is: why not use `max(dp[i-1][j],dp[i][j-1],dp[i-1][j-1])`?

The newly visited `text1[i]` or `text2[j]` may contribute to extending the longest common subsequence; they simply cannot contribute at the same time. For example:

text1 = aced

text2 = aefkc

At this point, `i = 2` and `j = 3`, and the longest common subsequence of `ace` and `aefk` is `a`.

Now move `j` forward. Although `text1[i] != text2[j]`, `text2[0:j]` has become `aefkc`, and the newly added `c` makes the longest common subsequence `ac`.

The recurrence has been obtained. Next determine the boundary conditions.

`dp[0][j]` represents the length of the longest common subsequence formed by `text1[0]` and `text2[0:j]`. Therefore, we only need to determine whether `text2[0:j]` contains `text1[0]`, which means checking whether any visited element equals `text1[0]`.

If they are equal, set the current `j` and all subsequent `dp[0][j]` values to 1 and terminate the loop. Otherwise, continue to the end and set `dp[0][j]` to 0.

`dp[i][0]` follows the same logic: traverse `text1[0:i]` and check whether an element equal to `text2[0]` exists.

Java

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();
        int[][] dp = new int[m][n];

        // initialize dp[i][0]
        for(int i = 0; i < m; i++) {
            if(text1.charAt(i) == text2.charAt(0)) {
                for(int k = i; k < m; k++) {
                    dp[k][0] = 1;
                }
                break;
            }
        }

        // initialize dp[0][j]
        for(int j = 0; j < n; j++) {
            if(text2.charAt(j) == text1.charAt(0)) {
                for(int k = j; k < n; k++) {
                    dp[0][k] = 1;
                }
                break;
            }
        }

        for(int i = 1; i < m; i++) {
            for(int j = 1; j < n; j++) {
                if(text1.charAt(i) == text2.charAt(j)) {
                    dp[i][j] = dp[i-1][j-1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i][j-1], dp[i-1][j]);
                }
            }
        }
        return dp[m-1][n-1];
    }
}
```

Of course, if we let `text1[0:i]` represent the prefix starting at index 0 with length `i`, we do not need the two cumbersome `for` loops for initialization. Since the length of the common subsequence of an empty string and any string is 0, both `dp[i][0]` and `dp[0][j]` only need to be initialized to 0. However, note that when allocating the array, it should be a two-dimensional array of `(m+1) × (n+1)`, and we should compare whether `text1[i-1]` equals `text2[j-1]`.

Python

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m = len(text1)
        n = len(text2)

        dp = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1) :
            for j in range(1, n + 1) :
                if text1[i - 1] == text2[j - 1] :
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else :
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        return dp[m][n]
```

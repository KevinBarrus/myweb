[347. Top K Frequent Elements - LeetCode](https://leetcode.cn/problems/top-k-frequent-elements/description/?envType=study-plan-v2&envId=top-100-liked)

Given an integer array `nums` and an integer `k`, return the `k` most frequent elements. You may return the answer in **any order**.

**Example 1:**

**Input:** nums = [1,1,1,2,2,3], k = 2

**Output:** [1,2]

**Example 2:**

**Input:** nums = [1], k = 1

**Output:** [1]

**Example 3:**

**Input:** nums = [1,2,1,2,1,2,3,1,3,2], k = 2

**Output:** [1,2]

**Constraints:**

- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 104`
- `k` is in the range `[1, the number of distinct elements in the array]`.
- The input guarantees that the answer is unique. In other words, the set of the `k` most frequent elements in the array is unique.

**Follow-up:** The time complexity of your algorithm **must** be better than `O(n log n)`, where `n` is the size of the array.

Since frequency is involved, a hash table immediately comes to mind. First use a hash table to store the number of occurrences of each element, with the element as the key and its occurrence count as the value. The task becomes sorting the values and taking the last `k` elements.

First consider the special case where multiple elements have the same occurrence count. The solution is to put elements with the same occurrence count into the same bucket, so there is no need to sort the elements within a bucket.

Let the maximum occurrence count be `max_fre`, and create a list `buckets` of size `max_fre + 1`, where `buckets[i]` is the list of elements that occur `i` times. Then traverse the hash table and move each element into `buckets`.

Next it is simple: traverse `buckets` in reverse order and add the elements in `buckets[i]` to the answer. Return when the number of elements in the answer reaches `k`.

```python
import sys
from typing import List
from collections import Counter

def solve() -> None:
    data = sys.stdin.read().strip().split()
    k = int(data[-1])
    nums = list(map(int, data[:-1]))
    ans = topKFrequent(nums, k)
    print(" ".join(map(str, ans)))

def topKFrequent(nums: List[int], k: int) -> List[int]:
    # count the occurrences of each element
    cnt = Counter(nums)
    # record the maximum occurrence count
    max_fre = max(cnt.values())

    # put elements with the same occurrence count into the same bucket
    buckets = [[] for _ in range(max_fre + 1)]
    for element, e_cnt in cnt.items():
        buckets[e_cnt].append(element)

    # traverse buckets in reverse order and add the k most frequent elements to the answer
    ans = []
    for bucket in reversed(buckets):
        ans += bucket
        if len(ans) == k:
            return ans

if __name__ == "__main__":
    solve()
```

[763. Partition Labels - LeetCode](https://leetcode.cn/problems/partition-labels/description/?envType=study-plan-v2&envId=top-100-liked)

You are given a string `s`. We want to partition this string into as many parts as possible so that each letter appears in at most one part. For example, the string `"ababcc"` can be partitioned into `["abab", "cc"]`, but partitions such as `["aba", "bcc"]` or `["ab", "ab", "cc"]` are invalid.

Note that the partition must satisfy this condition: concatenating all partitioned parts in order produces `s` again.

Return a list of the lengths of the string parts.

**Example 1:**

**Input:** s = "ababcbacadefegdehijhklij"
**Output:** [9,7,8]
**Explanation:**
The partitions are "ababcbaca", "defegde", and "hijhklij".
Each letter appears in at most one part.
Partitions such as "ababcbacadefegde", "hijhklij" are incorrect because they contain fewer parts.

**Example 2:**

**Input:** s = "eccbbbbdec"
**Output:** [10]

**Constraints:**

- `1 <= s.length <= 500`
- `s` consists only of lowercase English letters.

Record the interval in which each character appears. Take Example 1:

`s = ababcbacadefegdehijhklij`

| Letter | Indices | Index interval |
| --- | -------- | ------- |
| a | 0,2,6,8 | [0,8] |
| b | 1,3,5 | [1,5] |
| c | 4,7 | [4,7] |
| d | 9,14 | [9,14] |
| e | 10,12,15 | [10,15] |
| f | 11 | [11,11] |
| g | 13 | [13,13] |
| h | 16,19 | [16,19] |
| i | 17,22 | [17,22] |
| j | 18,23 | [18,23] |
| k | 20 | [20,20] |
| l | 21 | [21,21] |

For example, the interval of d is `[9, 14]`, and the letters whose intervals overlap it are e, f, and g. Taking the union of these four intervals gives `[9, 15]`.

Similarly, the intervals in the table can be merged into `[0, 8], [9, 15], [16, 23]`.

Method:

1. Traverse `s` and find the last index where character `c` appears in `s`, `last[c]`.
2. Initialize the left and right endpoints of the interval currently being merged, `start` and `end`, to 0.
3. Traverse `s`. Since the current interval must contain every `s[i]`, update the maximum value of `end` with `last[s[i]]`.
4. If `i` equals `end`, the interval has been merged successfully; add `end - start + 1` to the answer array.
5. Set `start = end + 1` and begin the next merge.

```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        last = {c : i for i, c in enumerate(s)}
        ans = []
        start = end = 0
        for i, c in enumerate(s) :
            end = max(end, last[s[i]])
            if end == i :
                ans.append(end - start + 1)
                start = end + 1
        return ans
```

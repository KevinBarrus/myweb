[394. Decode String - LeetCode](https://leetcode.cn/problems/decode-string/description/?envType=study-plan-v2&envId=top-100-liked)

Given an encoded string, return its decoded string.

The encoding rule is: `k[encoded_string]`, which means that the `encoded_string` inside the square brackets is repeated exactly `k` times. Note that `k` is guaranteed to be a positive integer.

You may assume that the input string is always valid; the input string contains no extra spaces, and the square brackets in the input always satisfy the required format.

In addition, you may assume that the original data does not contain digits, and all digits only represent the repetition count `k`. For example, inputs such as `3a` or `2[4]` will not appear.

The test cases guarantee that the output length does not exceed `105`.

**Example 1:**

**Input:** s = "3[a]2[bc]"
**Output:** "aaabcbc"

**Example 2:**

**Input:** s = "3[a2[c]]"
**Output:** "accaccacc"

**Example 3:**

**Input:** s = "2[abc]3[cd]ef"
**Output:** "abcabccdcdcdef"

**Example 4:**

**Input:** s = "abc3[cd]xyz"
**Output:** "abccdcdcdxyz"

**Constraints:**

- `1 <= s.length <= 30`
- `s` consists of lowercase English letters, digits, and square brackets `'[]'`.
- `s` is guaranteed to be a **valid** input.
- All integers in `s` are in the range `[1, 300]`.

Clearly, a stack is more convenient. The key is that `[` and `]` must appear in matching pairs.

Step 1: Traverse `s`. As long as the character is not `]`, push it directly onto the stack.

Step 2: Once `]` is encountered, the conditions for decoding are ready. Find the left square bracket matching this right square bracket, namely the nearest left square bracket. Search backward and put the characters encountered during the backward search into a temporary string `sub`, because these characters will later be pushed back onto the stack. That is, while searching backward, if the character encountered is not `[`, pop it and put it into `sub`; if it is `[`, pop it directly without putting it into `sub`.

After this step, the string inside the matching pair of square brackets has been extracted.

Step 3: Extract the number before this pair of square brackets to determine how many times to repeat. The characters in `s` are characters, not numbers, so we need to calculate the numeric value. For example, for `46[abc]`, we cannot extract only 4 and 6; 4 and 6 together form the number 46. Therefore, traverse backward again. The loop condition is that the stack is not empty (because the number may be at the very beginning) and the last element of the stack is a digit. Use `k` to record the final value of the number and `base` to record the place value. Initially, `k` is 0 and `base` is 1. For each digit, add the digit multiplied by `base` to `k`, and then multiply `base` by 10. After the loop ends, the value of the number is `k`.

Step 4: Push `k` copies of `sub` onto the stack.

Nested expressions are also handled correctly, because we decode the innermost pair first.

```python
class Solution:
    def decodeString(self, s: str) -> str:
        stk = []
        for ch in s :
            # Step 1: push onto the stack if it is not ]
            if ch != ']' :
                stk.append(ch)
                continue

            # Step 2: decode, search backward for [, and put the characters into sub
            sub = ""
            while stk[-1] != '[' :
                sub = stk.pop() + sub # the popped element should be placed before sub

            stk.pop() # remove [

            # Step 3: extract the number
            k, base = 0, 1
            while stk and stk[-1].isdigit() :
                k += int(stk.pop()) * base
                base *= 10

            # Step 4: push k copies of sub onto the stack
            stk.append(k * sub)

        return "".join(stk)
```

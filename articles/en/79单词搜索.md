[79. Word Search - LeetCode](https://leetcode.cn/problems/word-search/?envType=study-plan-v2&envId=top-100-liked)

Given an `m x n` grid of characters `board` and a string `word`, return `true` if `word` exists in the grid; otherwise, return `false`.

The word must be formed by letters of sequentially adjacent cells, where adjacent cells are horizontally or vertically neighboring. The same cell may not be used more than once.

**Example 1:**

![](https://assets.leetcode.com/uploads/2020/11/04/word2.jpg)

**Input:** board = `[['A','B','C','E'],['S','F','C','S'],['A','D','E','E']]`, word = "ABCCED"
**Output:** true

**Example 2:**

![](https://assets.leetcode.com/uploads/2020/11/04/word-1.jpg)

**Input:** board = `[['A','B','C','E'],['S','F','C','S'],['A','D','E','E']]`, word = "SEE"
**Output:** true

**Example 3:**

![](https://assets.leetcode.com/uploads/2020/10/15/word3.jpg)

**Input:** board = `[['A','B','C','E'],['S','F','C','S'],['A','D','E','E']]`, word = "ABCB"
**Output:** false

**Constraints:**

- `m == board.length`
- `n = board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` and `word` consist only of uppercase and lowercase English letters.

**Follow-up:** Can you optimize the solution using search pruning so that it solves the problem faster for a larger `board`?

DFS is easy to think of. The idea is as follows:

Let `dfs(i, j, k)` mean that we are currently at cell `board[i][j]` and trying to match `word[k]`.

If `board[i][j] != word[k]`, return `false` directly.

If `board[i][j] == word[k]` and `k == len(word) - 1`, the last character of `word` has been reached, so return `true` directly.

If `board[i][j] == word[k]` and `k != len(word) - 1`, start DFS: enumerate the four cells `(x, y)` around `(i, j)`. If `(x, y)` is in bounds, recursively call `dfs(x, y, k + 1)`. If it returns `true`, `dfs(i, j, k)` also returns `true`. If all four calls return `false`, `dfs(i, j, k)` returns `false`.

Whenever `board[i][j]` is visited, set it to zero. If `dfs(i, j, k)` returns `false`, restore its original value. This avoids performing the same DFS repeatedly.

Notice Example 3: B appears twice in `word`, but only once in `board`, so the answer must be `false`. Therefore, first check whether the count of any letter in `word` is greater than its count in `board`. If so, return `false` directly without DFS.

Examples 1 and 2 also show that when searching visually, we first find the first letter of `word` and then start DFS. In Example 1 there are two As, and in Example 2 there are two Ss. Which one should start DFS?

Intuition tells us to start DFS with the letter that appears fewer times in `board`. For example, if `word = xyz`, and `board` contains a great many x's but only one z, we should locate z first and start DFS from there.

Let the first letter of `word` appear `x` times in `board`, and the last letter appear `y` times.

If `y < x`, reverse `word` and start DFS from its last letter, reducing the number of DFS calls.

```python
class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        cnt = Counter(c for row in board for c in row)
        # if any letter occurs more often in word than in board, return False directly
        if not Counter(word) <= cnt:
            return False

        if cnt[word[-1]] < cnt[word[0]]:
            word = word[::-1]

        m, n = len(board), len(board[0])
        def dfs(i: int, j: int, k: int) -> bool:
            if board[i][j] != word[k]:
                return False
            if k == len(word) - 1:
                return True
            board[i][j] = '' # mark as visited
            for x, y in (i, j - 1), (i, j + 1), (i - 1, j), (i + 1, j):
                if 0 <= x < m and 0 <= y < n and dfs(x, y, k + 1):
                    return True
            board[i][j] = word[k] # not found; restore
            return False
        return any(dfs(i, j, 0) for i in range(m) for j in range(n))
```

```python
import ast
from typing import List
from collections import Counter

def exist(board: List[List[str]], word: str) -> bool:
    cnt = Counter(c for row in board for c in row)
    if not Counter(word) <= cnt:
        return False

    if cnt[word[-1]] > cnt[word[0]]:
        word = word[::-1]

    m, n = len(board), len(board[0])
    def dfs(i: int, j: int, k: int) -> bool:
        if board[i][j] != word[k]:
            return False

        if k == len(word) - 1:
            return True

        board[i][j] = ''
        for x, y in (i, j - 1), (i, j + 1), (i + 1, j), (i - 1, j):
            if 0 <= x < m and 0 <= y < n and dfs(x, y, k + 1):
                return True

        board[i][j] = word[k]
        return False
    return any(dfs(i, j, 0) for i in range(m) for j in range(n))


def read_cases(filename):
    cases = []
    with open(filename, "r") as f:
        lines = [
            line.strip() for line in f if line.strip()
        ] # remove blank lines separating test cases

    for i in range(0, len(lines), 2):
        # every two lines form a new test case
        board_line = lines[i]
        word_line = lines[i + 1]

        board = ast.literal_eval(
            board_line.split("=", 1)[1].strip()
        )

        word = ast.literal_eval(
            word_line.split("=", 1)[1].strip()
        )

        cases.append(
            (board, word)
        )
    return cases


def main():
    cases = read_cases("case.txt")
    for board, word in cases:
        print(f"board = {board}")
        print(f"word = {word}")

        result = exist(board, word)
        print (f"result = {result}")
        print()

if __name__ == "__main__":
    main()
```

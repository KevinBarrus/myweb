[1. Two Sum - LeetCode](https://leetcode.cn/problems/two-sum/?envType=study-plan-v2&envId=top-100-liked)

Given an integer array `nums` and an integer `target`, find the two integers in the array whose sum is **equal to the target**, and return their array indices.

You may assume that each input has exactly one solution, and you may not use the same element twice.

You may return the answer in any order.



**Example 1:**

```
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, return [0, 1].
```

**Example 2:**

```
Input: nums = [3,2,4], target = 6
Output: [1,2]
```

**Example 3:**

```
Input: nums = [3,3], target = 6
Output: [0,1]
```



**Constraints:**

- `2 <= nums.length <= 104`
- `-109 <= nums[i] <= 109`
- `-109 <= target <= 109`
- **There is exactly one valid answer**



**Follow-up:** Can you design an algorithm with a time complexity less than `O(n^2)`?



Brute force

When iterating over `x`, search for `target-x` starting from the position after `x`. The reason for searching from there is that the elements before `x` must already have been matched with `x`.

java:

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        for(int i=0;i<nums.length;i++) {
            for(int j=i+1;j<nums.length;j++) {
                if(nums[i]+nums[j]==target) {
                    return new int[]{i,j};
                }
            }
        }
        return new int[0];
    }
}
```

Go:

```go
func twoSum(nums []int, target int) []int {
    for i,v:=range nums {
        for j:=i+1;j<len(nums);j++ {
            if v+nums[j]==target {
                return []int{i,j};
            }
        }
    }
    return nil
}
```

C++:

```C++
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        int n=nums.size();
        for(int i=0;i<n;i++) {
            for(int j=i+1;j<n;j++) {
                if(nums[i]+nums[j]==target) {
                    return vector<int>{i,j};
                }
            }
        }
        return vector<int>{};
    }
};
```



Hash table

The outer loop cannot be avoided, so we can optimize the inner loop. In other words, is there a faster way to find `target-x`?

We can use a hash table. While iterating over `x`, check whether `target-x` exists in the hash table. That is, we cannot look forward because those elements have not been visited yet, but we can look backward to check whether `target-x` exists on the left side of `x`.

Java:

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        HashMap<Integer,Integer>mp=new HashMap<Integer,Integer>();
        for(int i=0;i<nums.length;i++) {
            if(mp.containsKey(target-nums[i])) {
                return new int[]{mp.get(target-nums[i]),i};
            }
            mp.put(nums[i],i);
        }
        return new int[0];
    }
}
```



Go:

```go
func twoSum(nums []int, target int) []int {
    mp:=map[int]int{}
    for i,x:=range nums {
        if k,ok:=mp[target-x];ok {
            return []int{k,i}
        }
        mp[x]=i
    }
    return nil;
}
```



C++:

```c++
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int,int>mp;
        for(int i=0;i<nums.size();i++) {
            auto it=mp.find(target-nums[i]);
            if(it!=mp.end()) {
                return {it->second,i};
            }
            mp[nums[i]]=i;
        }
        return {};
    }
};
```



Both C++'s `unordered_map` and Java's `HashMap` can only check whether a key exists. Therefore, the key should be the element value, and the value should be the element index.

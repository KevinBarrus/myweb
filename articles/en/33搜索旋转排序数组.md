[33. Search in Rotated Sorted Array - LeetCode](https://leetcode.cn/problems/search-in-rotated-sorted-array/description/?envType=study-plan-v2&envId=top-100-liked)

The integer array `nums` is sorted in ascending order, and all values in the array are **distinct**.

Before being passed to the function, `nums` is rotated to the **left** at an unknown index `k` (`0 <= k < nums.length`), so the array becomes `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]` (indexing starts at **0**). For example, rotating `[0,1,2,4,5,6,7]` to the left at index `3` may produce `[4,5,6,7,0,1,2]`.

Given the **rotated** array `nums` and an integer `target`, return the index of `target` if it exists in `nums`; otherwise, return `-1`.

You must design an algorithm with time complexity `O(log n)` to solve this problem.

**Example 1:**

**Input:** nums = [4,5,6,7,0,1,2], target = 0
**Output:** 4

**Example 2:**

**Input:** nums = [4,5,6,7,0,1,2], target = 3
**Output:** -1

**Example 3:**

**Input:** nums = [1], target = 0
**Output:** -1

**Constraints:**

- `1 <= nums.length <= 5000`
- `-104 <= nums[i] <= 104`
- Every value in `nums` is **unique**
- The input guarantees that `nums` was rotated at an unknown index
- `-104 <= target <= 104`

Because this is a rotated array, it has the following property:

For any number `x` in `nums`, compare it with `nums[n - 1]`:
- If `x > nums[n - 1]`, then `nums` has two increasing segments. Every element in the first increasing segment is greater than every element in the second increasing segment, and `x` is in the first segment.
- If `x <= nums[n - 1]`, then `x` is in the second increasing segment, or `nums` itself is increasing and has only one segment.

Let `x = nums[mid]` be the number being searched by binary search. To determine the positional relationship between `x` and `target`, compare both numbers with `nums[n - 1]`:
- If `target > nums[n - 1] >= x`, then `target` is in the first segment, `x` is in the second segment, and `target` is to the left of `x`.
- If `x > nums[n - 1] >= target`, then `x` is in the first segment, `target` is in the second segment, and `target` is to the right of `x`.
- Otherwise, `x` and `target` are in the same segment, so comparing `x` and `target` directly tells us which is on the left and which is on the right.

Once we know which is on the left and which is on the right, we can perform binary search.

```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = -1, len(nums) - 1
        while left + 1 < right:
            mid = (left + right) // 2
            x = nums[mid]
            if target > nums[-1] >= x:
                # target is in the first segment, x is in the second segment
                right = mid
            elif x > nums[-1] >= target:
                # target is in the second segment, x is in the first segment
                left = mid
            elif x >= target:
                # x and target are in the same segment, and x is to the right of target
                right = mid
            else:
                left = mid
        return right if nums[right] == target else -1
```

When should we use `left < right`, `left <= right`, or `left + 1 < right`?

For binary search, clarify three questions:

1. What interval is being maintained?
2. Should `mid` be retained?
3. Does the interval really become smaller?

If `left` initially equals 0 and the condition of the `while` loop is `left < right`, an infinite loop may occur. For example, when `left = 3` and `right = 4`, `mid = 3`; if the second branch is taken, `mid` is assigned to `left`, so the interval does not become smaller and the loop never ends.

Can we use `left = mid + 1`? Yes, but we cannot simultaneously use `right = mid - 1`. In the `elif nums[mid] >= target` branch, we cannot write `right = mid - 1`, but in the `if target > nums[-1] >= nums[mid]` branch we can write `right = mid - 1`. This is because the `elif` branch is equivalent to `nums[mid] == target or nums[mid] > target`: `nums[mid]` may be the answer. If we write `right = mid - 1`, we exclude the answer from the interval.

So we can also write:
```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        while left < right:
            mid = (left + right) // 2
            x = nums[mid]
            if target > nums[-1] >= x:
                # target is in the first segment, x is in the second segment
                right = mid - 1
            elif x > nums[-1] >= target:
                # target is in the second segment, x is in the first segment
                left = mid + 1
            elif x >= target:
                # x and target are in the same segment, and x is to the right of target
                right = mid
            else:
                left = mid + 1
        return right if nums[right] == target else -1
```

from typing import List
import ast

def search(nums: List[int], target: int) -> int:
    left, right = -1, len(nums) - 1
    while left + 1 < right:
        mid = (left + right) // 2
        x = nums[mid]
        if target > nums[-1] >= x:
            # target is in the first segment, x is in the second segment
            right = mid
        elif x > nums[-1] >= target:
            # x is in the first segment, target is in the second segment
            left = mid
        elif x >= target:
            # x and target are in the same segment, and x is to the right of target
            right = mid
        else:
            # x and target are in the same segment, and x is to the left of target
            left = mid
    return right if nums[right] == target else -1

def read_cases(filename: str):
    cases = []
    with open(filename, "r") as f:
        lines = [
            line.strip() for line in f
        ]

    for i in range(0, len(lines), 2):
        nums = ast.literal_eval(
            lines[i]
        )
        target = ast.literal_eval(
            lines[i + 1]
        )
        cases.append(
            (nums, target)
        )
    return cases

def main():
    cases = read_cases("cases.txt")
    for nums, target in cases:
        res = search(nums, target)
        print(f"nums = {nums}")
        print(f"target = {target}")
        print(f"result = {res}")
        print()

if __name__ == "__main__":
    main()
